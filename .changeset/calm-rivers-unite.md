Merged `theme-all.css` and `theme-basic.css` into the package entry `theme.css`, and exposed every stylesheet as a subpath of the package `exports` field. The entry carries the basic modules (the CSS reset, the variable defaults and the basic HTML tag styles), and each feature module is imported by its own subpath such as `@vivliostyle/theme-base/figure`, and the `css/lib/` distinction is gone. The stylesheets of the official themes and the scaffold generated by `create-vivliostyle-theme` import the new paths.

BREAKING CHANGE: `theme-all.css` and `theme-basic.css` no longer exist. Import the package entry instead of `theme-basic.css`, and add the feature modules you use instead of `theme-all.css`:

```css
/* Before */
@import url(@vivliostyle/theme-base/theme-all.css);

/* After */
@import '@vivliostyle/theme-base';
@import '@vivliostyle/theme-base/appendix';
@import '@vivliostyle/theme-base/citation';
@import '@vivliostyle/theme-base/endnote';
@import '@vivliostyle/theme-base/equation';
@import '@vivliostyle/theme-base/figure';
@import '@vivliostyle/theme-base/footnote';
@import '@vivliostyle/theme-base/listing';
@import '@vivliostyle/theme-base/page';
@import '@vivliostyle/theme-base/section';
@import '@vivliostyle/theme-base/table';
@import '@vivliostyle/theme-base/theorem';
@import '@vivliostyle/theme-base/toc';
```

Individually imported stylesheets move the same way: `css/<module>.css` and `css/lib/<module>` both become `@vivliostyle/theme-base/<module>`, external-link footnotes (`css/footnote-external-link.css`) become `@vivliostyle/theme-base/footnote/external-links`, and the Prism themes are imported as `@vivliostyle/theme-base/prism/theme-prism` and `@vivliostyle/theme-base/prism/theme-okaidia`.
