Moved the opt-in stylesheets under `css/lib/`. `css/footnote-external-link.css` is now the `css/lib/footnote-external-link` module and is no longer part of `theme-all.css`, and the Prism base stylesheet `css/lib/prism/base.css` became the entry of the `css/lib/prism` module. Each `lib` module is a directory with an `index.css` entry exposed through the package `exports` field, so it is imported by its directory name. The stylesheets of `@vivliostyle/theme-slide` and `@vivliostyle/theme-techbook` and the scaffold generated by `create-vivliostyle-theme` import the new Prism path.

BREAKING CHANGE: `theme-all.css` no longer turns external links into footnotes — import `css/lib/footnote-external-link` explicitly to keep them. If you import these stylesheets individually, update the paths:

```css
/* Before */
@import url(@vivliostyle/theme-base/css/footnote-external-link.css);
@import url(@vivliostyle/theme-base/css/lib/prism/base.css);

/* After */
@import url(@vivliostyle/theme-base/css/lib/footnote-external-link);
@import url(@vivliostyle/theme-base/css/lib/prism);
```

The syntax highlighting themes keep their paths: `css/lib/prism/theme-prism.css` and `css/lib/prism/theme-okaidia.css`.
