Turned the opt-in stylesheets into `exports` subpaths. `css/footnote-external-link.css` is now the `footnote/external-links` stylesheet of the `footnote` module and is no longer imported by default, and the Prism base stylesheet `css/lib/prism/base.css` became the entry of the `prism` module. The stylesheets of `@vivliostyle/theme-slide` and `@vivliostyle/theme-techbook` and the scaffold generated by `create-vivliostyle-theme` import the new Prism path.

BREAKING CHANGE: External links are no longer turned into footnotes by default. Import `footnote/external-links` explicitly to keep them. If you import these stylesheets individually, update the paths:

```css
/* Before */
@import url(@vivliostyle/theme-base/css/footnote-external-link.css);
@import url(@vivliostyle/theme-base/css/lib/prism/base.css);

/* After */
@import '@vivliostyle/theme-base/footnote/external-links';
@import '@vivliostyle/theme-base/prism';
```

The syntax highlighting themes are imported as `@vivliostyle/theme-base/prism/theme-prism` and `@vivliostyle/theme-base/prism/theme-okaidia`.
