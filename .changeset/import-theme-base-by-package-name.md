Import `@vivliostyle/theme-base` by its npm package name instead of a path relative to the themes directory. Each stylesheet now reads `@import url(@vivliostyle/theme-base/…)`, and the `theme` array of `vivliostyle.config.js` no longer has to repeat the same list of base stylesheets. The scaffold generated by `create-vivliostyle-theme` is written the same way.

BREAKING CHANGE: The `@vivliostyle/cli` peer dependency is raised to `>=11.3.0` (previously `>=11`). Resolving npm package names in `@import` rules was added in that release, so earlier versions cannot load these stylesheets.
