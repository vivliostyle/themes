# @vivliostyle/theme-step-badge-caution-box

横組み2段の学校向け実験マニュアルテーマ。アクセントカラーを見出しバッジ・STEPバッジ・安全上の注意ボックスに限定反復し、器具一覧の表とピクトグラム付きの安全注意、番号付き操作手順を組む。

## 使い方

```css
@import '@vivliostyle/theme-step-badge-caution-box';
```

原稿の書き方:

- 1 実験 = 1 見出し (`# 実験の題`) で、`h1` ごとに改ページする。実験は `{.experiment}`、安全の手引きは `{.safety}` を付けると、赤バッジの番号 (`実験1` / `安全1`) がカウンタから振られる。番号を持たないページは `{data-badge="実験編"}` のようにバッジの文字を原稿に書く。
- 2段組は `h1` の節に掛かる。見出しとリード文 (`<p class="lead">`) は段抜きになる。1ページに収まらない分量を書いた場合は切り捨てず次ページへ流れる。
- 柱の左に出す章名は `<p class="chapter-name">第4章　章名</p>` と書く (紙面には出ない)。右にはその見出しが入る。
- 操作手順は `<div class="steps">` で包んだ番号付きリスト 1 つにまとめる。STEP バッジの数字はリストの順に振られる。
- 図は `![キャプション](fig.svg)` で、番号 (`図1`) はページごとに振り直される。もくじのページ番号は `<a href="#id" data-ref="page"></a>`、実験への参照は `[題](#id){data-ref=exp}` と書く。

## カスタマイズ

`:root` で以下の変数を上書きしてカスタマイズできる。

| 変数                                  | 既定値                       | 説明                                       |
| ------------------------------------- | ---------------------------- | ------------------------------------------ |
| `--vs-theme-step-badge-caution-box--color-accent`            | `--vs-color-foreground-alt` と同じ | 見出しバッジ・STEPバッジ・注意ボックスの赤 |
