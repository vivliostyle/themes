# 市場構造を読み解く

## 市場の輪郭はどこにあるか

市場を分析する前に、市場そのものを定義しなければならない。当然の手続きに見えて、これは実務でしばしば省かれる。業界統計の区分がそのまま市場として扱われ、統計が変わらないかぎり市場も変わらないという前提が、誰にも点検されないまま共有されてしまうのである。

輪郭をどこに引くかは、分析の結論そのものを左右する。広く取れば自社のシェアは小さく見え、投資が足りないという診断が出る。狭く取ればシェアは大きく見え、守るべき地位があるという診断になる。同じ事業を見ていながら、線の引き方ひとつで処方は正反対になりうる。

線を引く原則は一つしかない。買い手にとって置き換えが利くかどうかである。技術的に似ているかどうかでも、業界団体の分類が同じかどうかでもない。買い手が予算と用途を前にして比較の{俎上|そじょう}に載せるものは、どれほど姿が違っていても同じ市場にある。

<a href="#fig-layers" data-ref="fig"></a>は、この原則を三つの層として描いたものである。中核市場は、買い手が同じ用途で日常的に見{較|くら}べる製品群を指す。隣接市場は、それ自体は代替にならないが、同じ予算の枠を奪い合う領域である。代替市場は、製品の形がまるで違うのに、買い手の困りごとを別の方法で解いてしまう領域を指す。

三つの層は固定されていない。代替市場の技術が成熟すれば、それはやがて中核市場の一部になる。だから分析では、いま競合と呼んでいる相手の外側に、必ずもう二つの円を描いておかねばならない。{侵食|しんしょく}の速度を決めるのは技術の進歩そのものではなく、買い手がその技術を学習する速度である。

輪郭が定まったら、内側を切り分ける。切り分けの軸は用途・地域・購買主体の三つが基本だが、実務で優先すべきは成長率の差が最も大きく開く軸である。差の開かない軸で切っても、区分の数が増えるだけで打ち手は変わらない。

<a href="#tbl-yoto" data-ref="tbl"></a>は、業務用小型ポンプ市場を用途で四つに切ったものである。市場全体では年七％台の成長が続いている。だがこの平均値は、ほとんど何も語っていない。全体の四割を占める標準がすでに一％台の{停滞|ていたい}に入っている一方で、排水再生は二割近い伸びを示している。平均だけを見て成熟市場と結論した企業は、内側で進む入れ替わりを見落とす。

市場の輪郭とセグメントの切り方は、分析の入口であって結論ではない。しかし入口を間違えれば、その先にどれほど精緻な分析を積んでも成果には結びつかない。

市場シェアは、企業活動の成果を映す代表的な指標でありながら、それ自体は売上の大小を言い換えたものにすぎない。重要なのは、その数値がどのような要因の積み上げで形づくられているかである。

シェアを分解する枠組みは数多いが、ここでは三つの要素に{絞|しぼ}る。買い手に届いているか、届いた先で価格に耐えているか、そして一度買った買い手が戻ってくるか。この三つである。どれも単独では説明力を持たないが、掛け合わせるとシェアの{輪郭|りんかく}が見えてくる。

第一の要素は①販売網の密度である。取扱店舗数や{棚割|たなわり}の占有率で測られ、密度が高いほど到達コストは下がる。<a href="#tbl-3sha" data-ref="tbl"></a>でアオバ電機の密度指数が競合を上回っているのは、二十年かけて地場の設備工事店を{系列|けいれつ}化してきた結果であり、一年や二年で追いつけるものではない。

第二は②価格弾力性で、弾力性が競合より小さければ値上げの局面でも需要を維持しやすい。大和井工機の弾力性が三社で最も大きいのは、主力の高圧仕様が入札で選ばれる製品だからである。入札は価格以外の差を見えなくする装置であり、そこで戦うかぎり弾力性は下がらない。

第三は③反復購買率である。アオバ電機のそれが四割台に乗っているのは、製品の性能よりも保守契約の設計によるところが大きい。買い替えの意思決定が「検討」ではなく「更新」として処理されるようになったとき、反復購買率は跳ね上がる。

<a href="#fig-matrix" data-ref="fig"></a>は、この三要素で測った四つの製品群を、市場の成長率と相対シェアの二軸に並べたものである。売上の半分を占める標準はすでに成長を止めており、そこで生まれる余剰が薬液対応と排水再生を支えている。とりわけ排水再生は、伸びは速いが首位との差がまだ開いている。資源を追加するか手を引くかの判断は、市場が固まる前にしか下せない。

三要素は独立して働くのではなく相互に影響し合う。販売網が密であれば反復購買の機会も増え、反復購買が積み上がれば価格弾力性は小さくなる。<a href="#fig-matrix" data-ref="fig"></a>と<a href="#tbl-3sha" data-ref="tbl"></a>を併せて読めば、各社がどの要素を強みとしてシェアを構成しているかを定量的に{把握|はあく}できる。施策は三要素の相互作用を織り込んで設計されねばならない。

高い利益率は、それ自体が参入の{誘因|ゆういん}である。放置されている高収益市場というものは、原理的に存在しない。したがって市場構造の分析には、なぜ他社が入ってこないのかという問いが必ず含まれていなければならない。この問いに答えられないなら、いま手にしている利益は借りものだと考えたほうがよい。

参入障壁は五つの要素に分けて測るとよい。初期設備投資、認証と規格、販売網、切替コスト、そして実績要件である。<a href="#fig-barrier" data-ref="fig"></a>は、業務用小型ポンプ市場についてこの五要素の高さを指数化したものだ。指数は最も高い要素を百とし、新規参入者が越えるべき負担の相対的な重さを表している。

目を引くのは、金額で測れる障壁ほど低いという点である。初期設備投資の指数は四十台にとどまる。{鋳造|ちゅうぞう}も加工も外部に委託でき、設備をひとつも持たずに参入する道はすでに開かれている。一方で実績要件と販売網は八割を超える高さを保っている。買い手が求めているのは製品そのものではなく、止まらないことの証明であり、その証明は時間でしか作れない。

五つの要素は、どれも自社が意図して築いたものとはかぎらない。認証と規格は行政や標準化団体が定めたものであり、切替コストは買い手の側の都合で生じている。他人の用意した壁の内側で商売をしているという自覚がなければ、壁の管理者が方針を変えた日に、事業は理由もわからないまま{傾|かたむ}く。規格の改定案や標準化団体の議事録に目を通すという地味な作業が、参入障壁の分析では最も割に合う手段になることも多い。

ただし、障壁は{堀|ほり}ではない。堀は掘った深さのまま残るが、障壁は市場の側の条件が変われば独りでに低くなる。近年、薬液対応の一部用途に参入した湊野テクノスは、自社では一台も納めていない段階から、他社製ポンプの保守データを解析する{助言|じょげん}サービスを先に売った。最も高い壁であるはずの実績要件を、製品ではなく情報で{迂回|うかい}したのである。

障壁の高さは、測った瞬間から{陳腐化|ちんぷか}する。だから重要なのは絶対値ではなく、どの要素がどの速度で低くなりつつあるかである。五つのうち一つでも急速に下がっている要素があるなら、その市場の構造は数年で書き換わると考えてよい。

市場全体が生み出す利益は、価値連鎖の各段階に均等には配分されない。同じ市場に身を置きながら、どの段階を担うかによって収益性は数倍も違ってくる。市場の大きさと成長率だけを見て参入や撤退を論じる議論が空回りするのは、この配分の{偏|かたよ}りを勘定に入れていないからである。

<a href="#fig-chain" data-ref="fig"></a>は、業務用小型ポンプの価値連鎖を五つの段階に分け、各段階が市場全体の付加価値に占める比率と、その段階の営業利益率を並べたものである。読み取るべき点は一つに{絞|しぼ}られる。付加価値の四分の一を占めるにすぎない保守が、市場全体の利益のちょうど半分を生んでいる。

組立の付加価値は保守とさほど変わらない。それでも利益では遠く及ばないのは、利益率が三分の一しかないからである。製造業を{自認|じにん}する企業にとって認めがたい事実だが、この市場の利益の重心はすでに製造の外に移っている。

利益の{溜|た}まる場所は動く。かつて最も稼ぐ段階は組立だった。設計が標準化され、部材が共通化されるにつれて、そこで得られていた利益は買い手の側へ、あるいは保守の側へと流れ出した。移動の方向を決めているのは、買い手が不確実だと感じている場所がどこかという一点である。不確実さの残るところに、利益は{溜|た}まる。

配分図を描くときに{厄介|やっかい}なのは、段階の切り方である。細かく分けすぎれば、どの段階の数字も推計になり、{曖昧|あいまい}さだけが増える。粗く分ければ、利益の{偏|かたよ}りが平均に{均|なら}されて見えなくなる。目安は、社内の誰かが責任を持って数字を言える単位まで分け、それ以上は分けないことである。段階の名前が組織の呼び名と一致しないような配分図は、描いた本人以外には使われない。

したがって、自社は価値連鎖のどこにいるのかという問いは、どこにいたいのかという問いと切り離せない。アオバ電機が保守要員の採用を製造要員より優先しているのは、五年前にこの配分図を描いてしまったからにほかならない。

## 需要の変化を先読みする

ここまでの各節で扱ってきたのは、いずれも静止画である。市場の輪郭も、シェアの構成も、障壁の高さも、利益の配分も、ある時点の断面にすぎない。構造分析の値打ちは、断面をきれいに撮ることではなく、次の断面を先に思い描くところにある。

需要の変化は、売上に現れる前に必ずどこかに現れている。問題は、それを見つける仕組みを持っているかどうかだ。<a href="#fig-steps" data-ref="fig"></a>に示したとおり、手順は三段階に整理できる。この三つを紙の上に書き出すだけで、変化への反応は目に見えて速くなる。

第一段階でつまずく企業が多い。先行指標の条件はただ一つ、自社の受注より先に動くことである。関連がありそうだという理由で選ばれた数字は、たいてい受注と同時か、その後に動く。それは指標ではなく結果の記録である。

第二段階の閾値は、事前に決めておかなければ意味を持たない。数字を見てから基準を決めるなら、人はいくらでも今回は例外だと言える。<a href="#tbl-shihyo" data-ref="tbl"></a>の目安が{素|そ}っ気ない形をしているのは、解釈の余地を残さないためである。

第三段階では、閾値に触れたときに誰が何をするかまで決めておく。予測の精度を上げるには際限のない投資が要るが、反応の速度を上げるのはたいてい取り決めだけで済む。

変化を先読みするとは、未来を言い当てることではない。当たらなかったときの損失を、あらかじめ小さくしておくことである。

## 本章の要点

本章では、市場構造を読み解くための道具を四つ扱った。輪郭、位置、障壁、配分の四つである。<a href="#fig-quad" data-ref="fig"></a>に、それぞれの問いと答え方をまとめておく。

四つの問いは、順に答えていくものであって、同時に答えられるものではない。輪郭を定めないまま位置を測れば、シェアの数値はいくらでも{恣意的|しいてき}になる。位置を測らないまま障壁を論じれば、そもそも何を守るべきかが定まらない。障壁を測らないまま利益の配分を論じれば、いま稼げている段階が明日も稼げるという根拠のない前提が入り込む。

四つの問いに答えるための材料は、たいてい社内に{揃|そろ}っている。営業日報にも、保守の記録にも、見積の履歴にも、市場の構造は断片として書き込まれている。足りないのは情報そのものではなく、それを四つの問いの形に組み替える手間である。外部の調査を買う前に、まず自社の帳簿を読み直したほうがよい場合は少なくない。

そして四つのいずれも、一度答えれば済むものではない。本章に並べた数値は、あくまである時点の断面にすぎない。分析の質を決めるのは、道具の{精緻|せいち}さよりも、断面を撮り直す頻度である。年に一度の更新で足りる市場もあれば、四半期ごとに撮り直しても遅い市場もある。その周期を決めること自体が、構造分析の一部だと考えたほうがよい。

次章では、読み解いた構造の上に、自社の資源をどう配置するかを扱う。構造の理解は、配置の{巧拙|こうせつ}を通じてしか成果に変わらない。
