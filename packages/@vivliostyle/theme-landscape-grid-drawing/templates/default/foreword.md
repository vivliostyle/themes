# 構築の余白 #

建築は、建てられたものだけでできているわけではない。柱と柱のあいだ、屋根と地面のあいだ、囲われた部屋と外気とのあいだには、材料の名を持たない領域がいくつも挟まっている。本展「構築の余白」は、碧海県内で四半世紀にわたって小さな建築をつくり続けてきた三雲宗久の仕事から四作を選び、その挟まれた領域がどのように寸法として決められていったのかを追う試みである。

選んだのは、書庫、集会所、住宅、公園の休息舎という、規模も用途もばらばらな四つである。延床面積はいずれも140平方メートルに満たず、構造はすべて木造軸組を基本とする。派手な形はどこにもない。それでも四つを並べると、平面図のうえで最も広い面積を与えられているのが、名前のつけにくい場所であることに気づく。

書庫では、自立した書架の厚みが囲い込む読書の場がそれにあたる。集会所では、桁からさらに1820出した庇が地面に落とす影の帯。住宅では、四周を壁で閉じたなかに正方形に抜かれた光庭。休息舎では、屋根と柱四本しか持たない土間のテラス。いずれも壁で仕切られておらず、家具も置かれていない。

設計者はこれらを「使い方を決めない場所」と呼ぶ。決めないことは、放置とは異なる。庇の出は1820でなければならず、光庭は正方形でなければならない。決めないための寸法を決める、という手間のかかる作業が、四つの図面のうえには等しく積まれている。本展が図面を主役に据えたのは、その手間の痕跡が図面にしか残らないからである。

会場に並ぶのは原図12点、複製図36点、そして縮尺模型6点だけである。竣工写真は一枚も展示しない。写真は建築を一瞬の像に固定し、見る者にその場に立った気にさせてしまう。図面はそうはいかない。寸法と線種の約束事を読み替えながら、見る者が自分の速度で空間を立ち上げるほかない。

その遅さこそを、来場者と共有したいと考えた。平面図の太い線が壁であり、細い破線が上部の軒であることを知るまでには、いくらか時間がかかる。だがいったん読めるようになると、線の集まりは厚みや影に変わり、紙の上に立てるようになる。図面を読むという行為は、それ自体がひとつの建築体験である。

出品した原図には、鉛筆で書き込まれた修正の跡がそのまま残っている。消しゴムで消しきれなかった数字、線の脇に小さく添えられた別案の寸法、余白に引かれた検討中の断面。設計者はこれらを恥ずかしいと言ったが、そのままの状態で展示することを最終的に承諾してくださった。決定に至るまでの逡巡は、決定そのものと同じだけの情報を含んでいる。

模型は1:50を四点、1:20を二点。1:20の二点は、書庫の書架まわりと、集会所の軒先の納まりを抜き出したものである。図面では数ミリの指示にすぎない見付や見込みが、この縮尺になると手のなかで確かめられる大きさになる。図面と模型のあいだを往復しながら見ていただきたい。

会場構成も設計者自身が担当した。第2展示室の中央に高さ1200ミリの展示台を四つ置き、それぞれの上に模型を、背後の壁に対応する図面を掛ける。展示台の間隔は各作品の余白の実寸から決められており、来場者はその寸法のなかを歩くことになる。会場そのものが五つ目の「余白」として設計されている、と言ってもよい。

本図録は展示の記録ではなく、展示と並走する別の器として編んだ。B4判横という判型は、原図を無理なく縮小して収めるために選んでいる。各作品の頁は上半分に平面・立面・断面の三面を、下半分に設計者による解説と建築概要を配し、図面と言葉が同じ紙面で向き合うように組んだ。方眼の地は、図面がもともと置かれていた製図台の記憶である。

四つの建築は、いずれも来場者が訪ねられる場所にはない。書庫と住宅は個人の所有であり、集会所は集落の管理下にある。公開されているのは休息舎だけである。だからこそ本展は、図面という代理を通してしか成立しない。ここに掛かった線の束が、行けない場所への通路として働くことを願っている。

末筆となったが、貴重な原図の出品を快諾された三雲建築設計室、および四作の建築主の皆さまに、あらためて御礼を申し上げる。
