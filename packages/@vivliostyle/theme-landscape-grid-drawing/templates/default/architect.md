# 設計者略歴 #

三雲宗久（みくも・むねひさ）は1974年、碧海県苫緒町に生まれた。祖父の代から続く建具屋の作業場が家の裏にあり、鉋屑の匂いと木を挽く音のなかで育っている。木の反りや目切れを見分けることを覚えたのは製図を学ぶよりずっと前だった、と本人は語る。

県内の工業高校で建築を学び、卒業後に県外の大学へ進んだ。九年間を住宅専門の設計事務所で過ごしたのち、2006年に汐那町の旧郵便局舎を借りて三雲建築設計室を開いている。以来、事務所の所員は本人を含めて三名を超えたことがない。受けられる仕事の量を、自分の目が届く範囲に合わせている。

設計の進め方は一貫している。敷地に通う回数を数え、その回数が二十を超えるまでは平面を描かない。二十という数字に根拠はないが、季節が一巡りしないうちに描きはじめると必ず後悔する、というのが事務所の経験則になっている。

通うあいだに記録するのは、光の入る角度でも、風向きでもない。だれがどの道を歩き、どこで立ち止まるかである。集会所の設計では、農道を通る一輪車の幅と、雨の日にそれが止まる位置を測っている。土間の寸法はそこから決まった。

描きはじめてからは、原寸に近い縮尺の断面を何十枚も重ねて、床から手の届く高さまでの寸法を確かめていく。腰を掛ける高さ、肘を置く高さ、本を取る高さ。立面はその結果として最後に決まる。外観の検討にほとんど時間を割かないのは、外から見た姿を軽んじているからではなく、内側の寸法が正しければ外は自ずと決まると考えているためである。

木造軸組を基本とするのは構法への信条というより、地元の工務店と同じ言葉で話せる範囲に納めるためだと説明する。特殊な納まりを避け、材の寸法を流通しているものに揃える。図面に描いた線が、そのまま現場で刻まれる線であること。設計者にとってはそれが最低限の条件である。

建具屋の出自は納まりの細部に表れる。敷居と鴨居の見付を揃えること、板の継ぎ目を柱心からずらすこと、金物を見せないこと。いずれも図面のうえでは数ミリの指示にすぎないが、竣工した建築ではその積み重ねが陰影の細かさとして立ち上がる。

本展に出品した原図の多くに、鉛筆で書き込まれた修正の跡が残されている。数字を消して書き直した箇所、余白に引かれた別案の断面、寸法線の脇に小さく添えられた疑問符。図面は清書された結果ではなく、考えが進んだ順に堆積した層である、というのが設計者の言い分である。

近年は県内の公共施設の設計にも携わり、2022年に碧海建築文化賞、2025年に同賞の大賞を受けた。受賞にあたっての談話では「小さい建築ばかりを続けてきたので、大きいものの設計の仕方をまだ知らない」と述べている。

小さいことは制約ではなく方法である、とも書いている。四十平方メートルの書庫であれば、床から天井までのすべての寸法を一人で決めきることができる。決めきったものだけを世に出す、という態度が、二十年のあいだ規模を選ばせてきた。

図面はいまも手で描く。事務所には製図台が二台あり、そのうち一台は独立前から使っているものである。清書と申請の図面は電子化しているが、検討の段階で鉛筆を離すと寸法の重さがわからなくなる、というのが理由だという。本展の原図はすべてこの二台の上で描かれた。

四作の建築主とは、竣工後もほとんど年に一度は顔を合わせている。修繕の相談が入ることもあれば、庭の木が伸びたという報告だけのこともある。建てて渡して終わりにしない距離感が、次の設計の与条件をつくっているように見える。

本展に寄せて、設計者は次のように書いている。「図面は建てるための指示書だが、同時に、まだ建っていないものについて他人と話すための唯一の言語でもある。四つの仕事のうち三つは、建築主とのあいだで図面をはさんで交わした会話のほうが、完成した建物より長く残っている」。
