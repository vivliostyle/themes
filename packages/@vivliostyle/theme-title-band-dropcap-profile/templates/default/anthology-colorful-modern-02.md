# 硝子の午後、遠い汽笛 {#essay-glass}

深津　澪

<aside class="sidebar">

**深津　澪**<br />（ふかつ　みお）<br />エッセイスト

1978年、西日本の港町に生まれる。出版社勤務を経て、エッセイストとして独立。日常の風景や旅の記憶、家族や時間の気配を、静かなまなざしで綴る文章が人気。著書に『海の近くで深呼吸』『窓辺の手紙』『小さな旅のつづき』など多数。雑誌やウェブでの連載も多く、読者から寄せられた手紙に答える「澪の手紙箱」も好評を博している。

</aside>

<span class="dropcap">窓</span>から差しこむ午後の光は、硝子のコップの底にたまった水のように、静かにゆれていた。遠くで、汽笛がひとつ、風に溶けるように鳴る。あの音を聞くたび、私はいつも、知らない土地へ向かう誰かの背中を想像してしまう。見送る人も、迎える人もいない、ただ、自分の意志だけを携えていく旅。そんな旅が、ほんとうにあるのだろうかと、時々、思う。

子どものころ、港町に住んでいた。家の裏には線路があり、一日に何度も貨物列車が通りすぎた。貨車の赤や茶色が、窓のすき間からちらちらと見えるのが、なぜか好きだった。あの色の中には、遠くの匂いがする気がしたのだ。塩の匂い、鉄の匂い、それから、まだ見ぬ世界の匂い。

線路のむこうには、小さな造船所があった。夕方になると、鉄を打つ音が、決まった間隔で響いてくる。音と音のあいだに、海の気配がそっと入りこんでくるようだった。母は台所で野菜を刻みながら、その数を数えていたのだろうか。よく鳴る日だね、と一度だけ言って、あとは何も言わなかった。私は宿題の手をとめて、暮れかけていく窓の色をながめていた。

汽笛は、その音とはちがっていた。打つ音には終わりがあるけれど、汽笛には余韻というものがある。鳴りおえたあとも、しばらくは空気のどこかに残っていて、それがゆっくりと薄くなっていく。子どもだった私は、その薄くなっていく時間のほうが好きだった。音そのものよりも、音の消えていく途中に、なにか大事なものが隠れているような気がしていたのだ。

十二か十三のころ、一度だけ、その造船所の敷地に入れてもらったことがある。近所に住む人がそこで働いていて、日曜の午後なら誰もいないからと言って、通用口の鍵をそっとあけてくれたのだ。中は、思っていたよりもずっと静かだった。動いていない機械は、どれも眠っている生きもののように見えた。足もとの水たまりに油が薄く浮いて、のぞきこむたびに、虹のような色がゆっくりとかたちを変えた。

その人は、船はここでは完成しないのだと教えてくれた。この工場で組むのは船の一部だけで、あとは別の場所へ運ばれ、また別の誰かの手で継がれていく。だから自分たちは、自分の作ったものが海に浮かぶところを見ないのだ、と。さびしくないですか、と私は聞いた。その人はすこし笑って、見なくても浮かぶよ、と言った。それきり何も言わずに、水たまりを避けて歩きだした。

その日のことを、長いあいだ忘れていた。思い出したのは、ずっとあとになって、まったく別の港で汽笛を聞いたときだ。旅先の宿の窓を開けたら、暗い海のむこうから、あの音がした。低くて、少しかすれていて、子どものころに聞いたものとは似ても似つかない。それなのに、身体のほうが先に、あの日曜の午後を思い出していた。

大人になると、線路は遠ざかった。けれど、汽笛の音だけは、どこかで鳴りつづけている。忙しい日々のなかで、ふとした瞬間に、その音が胸の奥をすっとかすめていく。思い出というより、約束のようなものかもしれない。いつか、また、あの音のするほうへ行ってみたい――そう思いながら、今日も私は、目の前の小さな仕事をひとつずつ片づけていく。

見なくても浮かぶよ、という言葉を、私はときどき思い出す。あの日の水たまりの虹も、油の匂いも、もうずいぶん薄くなってしまったけれど、あの一言だけは、いまもはっきりとかたちを保っている。人の作るものは、たいてい、作った人の見えないところで役に立つ。文章もまた、そういうものなのだろうと思う。誰が読んだのかを知らないまま、それでも、どこかで役に立っていると思っておく。そう思っておかないと、書くという仕事は少しさびしすぎる。

硝子の午後は、いつも少し切ない。光はやさしいのに、どこかに影がある。けれど、その影があるからこそ、遠い汽笛の音が、いっそう澄んで聞こえてくるのだと思う。旅に出るのは、きっと、特別な勇気なんかじゃない。ただ、自分の中の静かな声に、そっと耳をすますこと。それだけで、私たちは、すでにどこかへ向かっているのかもしれない。
