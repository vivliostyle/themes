# 編者ノート　水のかたち

舟見　律子

<aside class="sidebar">

**舟見　律子**<br />（ふなみ　りつこ）<br />編集者

1969年生まれ。文芸誌の編集部に十八年在籍したのち独立し、随筆と紀行の選集を編む仕事を続けている。編著に『台所から出る旅』『十年後に読む手紙』。年に二度、書き手を招いて小さな朗読の会をひらいている。本書『随想の庭』は、その会で読まれた文章を出発点として編まれた。

</aside>

<span class="dropcap">五</span>篇を並べ終えてから、ようやく第二部の題が決まった。はじめは別の題を考えていたのだが、どれも収まりが悪い。校正刷りを机いっぱいに広げて上から眺めているうちに、五人が五人とも、水のそばで手を止めていることに気がついた。

深津さんは港の光を、榛原さんは砥石の水を、苅田さんは米を研ぐ音を書いた。樋渡さんの雨と、箕輪さんの自販機の光は、一見すると水から遠いようだが、どちらも、降ってくるものと落ちてくるものの話である。打ち合わせをしたわけではない。五人はたがいの原稿を読んでいないし、そもそも五篇のうち四篇は、この本のためではなく、まったく別の機会に書かれたものである。

編むというのは、書かれた時期も場所もばらばらの文章を、いま読むための順番に並べ直す作業にすぎない。並べ替えただけで文章が変わるはずはないのに、順番が決まると、たしかに読み心地が変わる。この不思議だけは、何年やっても飽きない。

随筆は書き手が手のうちを明かす形式だと思われがちだが、実際には逆のことが多い。よい随筆ほど、書き手はうまく隠れている。隠れたまま、読み手の記憶のほうを立ち上がらせる。この五篇を読んで、自分の家の台所や、子どものころの夕方を思い出した方がいるとすれば、それはひとえに五人の手柄である。

第三部には、また別の六人に集まっていただいた。題はまだ決めていない。並べ終えるまで、たぶん決まらないだろう。決まらないうちは、まだ読み方の固まっていない文章がそこにあるということで、編む側にとっては、そのほうがいくらか楽しい。
