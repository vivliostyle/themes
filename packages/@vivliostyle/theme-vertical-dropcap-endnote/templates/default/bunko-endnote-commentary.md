# 解説　　沈黙の庭を読む

<aside class="sidebar">

沈黙は省略ではなく、語りの様式である。

喜和の内面は一行も書かれない。

庭は手入れによってのみ庭でありつづける。

</aside>

{静|しず}謐な庭は、語ることの不在ではない。むしろ、語りの余白が凝縮された、内なる対話の{痕跡|こんせき}をとどめる装置として機能している[^1]。本書『月影拾遺』の中心に置かれた中篇「沈黙の庭」を読み終えたとき、読者の{裡|うち}に残るのは、筋の起伏でも人物の運命でもなく、あの荒れた庭の、湿った土と葉裏のにおいのようなものだろう。この小説では、ほとんど何も起こらない。だが、何も起こらないという印象そのものが、遠見志津の周到に組み立てた効果なのである。

舞台は、戦後まもない山あいの町{苫緒|とまお}である。製糸で栄えた旧家{柊|ひいらぎ}家の屋敷には、手入れの行き届かない広い庭が残されている。語り手の{鈴|すず}は十七歳。空襲で両親を失い、遠縁を頼ってこの家に引き取られ、老庭師{久松|ひさまつ}の下働きとして日を送っている。屋敷にはもうひとり、当主の妹{喜和|きわ}がいる。四十を過ぎた喜和は、戦争の終わったころからほとんど口をきかない。夕暮れになると庭の隅の石灯籠のそばに立ち、暗くなるまで動かない。

小説はこの三人の、言葉を欠いた共同生活を、季節の推移とともに淡々と追ってゆく。喜和がなぜ黙るのか、鈴は知りたいと願う。町にはいくつかの{噂|うわさ}がある。戦時中に隣家の{宇津木|うつぎ}の一家が離散したのは喜和の密告によるのだという者があり、逆に、喜和は告発を止めようとして果たせなかったのだという者もある。噂はどれも確かめようがなく、確かめられないまま庭の上に積もってゆく。

中篇は四つの季節に沿って四つの部分に分かれている。春の{芽掻|めか}き、梅雨の苔、秋の{剪定|せんてい}、冬の{雪吊|ゆきづ}り。章の見出しはなく、区切りは一行の空白だけで示される。読者はいつのまにか一年を歩かされ、最後の頁で、自分がひと巡りしたことに気づく。この円環の構造が、事件の不在をゆるやかに支えている。

鈴と久松の交わす言葉も、また少ない。二人は日の高いうちは黙って{鋏|はさみ}を使い、休みの時間に{白湯|さゆ}を飲む。作者はこの労働をきわめて具体的に書く。{熊手|くまで}の歯のあいだに詰まる濡れ落葉の重さ、{根締|ねじ}めの石の座りの悪さ、指の{節|ふし}に残る青くさいにおい。感情を語らない代わりに、手のひらの感触が読者へ手渡される。この小説でもっとも雄弁なのは、たしかに人の手である。

ここで注意しておきたいのは、作者が喜和の沈黙をついに一度も内側から書かないことである。喜和の心理を説明する文は、この中篇に一行も存在しない[^2]。読者に与えられるのは、鈴の目に映る喜和の背中と、地面に落ちる影と、季節ごとの{枝|えだ}打ちの音だけである。沈黙は、語られなかった内容としてではなく、語りの様式そのものとして差し出される。それゆえ本作を、隠された真相を当てる小説として読もうとすれば、かならず取り逃がすことになる。

中盤に一度だけ、外から人が来る。離散した宇津木家の{遺児|いじ}、{要|かなめ}が{復員|ふくいん}ののちに町を訪ね、柊家の門前に立つ場面である。喜和は縁側から動かない。要も声をかけない。二人はただ、庭を{隔|へだ}てて向かい合う。やがて要は帽子を取り、一礼して去る。四頁ほどのこの場面が、本篇の唯一の対決であり、しかも一言も交わされない。

久松にも、語られない過去がある。彼は南方から復員し、身寄りをなくして柊家に住みついたと、ただ一行だけ記される。作者は彼の戦争を書かない。書かないことによって、庭の手入れという反復が彼にとって何であるのかを、読者の側に考えさせる。三人はそれぞれ別の沈黙を抱えたまま、同じ庭に立っているのである。

庭がこの小説で担う役割は大きい。庭は自然ではない。人の手が入りつづけることによってのみ庭でありうる、きわめて人工的な場所である。久松が毎年おなじ枝を落とし、おなじ{苔|こけ}を{掻|か}き、おなじ{飛石|とびいし}の高さを直すのは、庭を美しくするためではなく、庭を終わらせないためだ[^3]。放っておけば十年で山に戻る、と彼は鈴に言う。くり返される手入れの描写は、単調でありながら、読み進めるほどに祈りに近い手触りを帯びてくる。

<aside class="sidebar">

庭は個の記憶と時代の記憶が交わる場。

月影は照らしながら輪郭を隠す。

語り手は判断をたえず留保する。

</aside>

その庭も、時代から切り離されてはいない。作中には、戦時中に庭石の半ばが供出され、大{楓|かえで}が{薪|たきぎ}にされかけた{挿話|そうわ}が、説明を欠いたままさりげなく置かれている。焼けた鉄柵の跡、埋め戻された{防空壕|ぼうくうごう}のくぼみ、名を削られた{手水鉢|ちょうずばち}。庭の構図は、時代の記憶と個人の記憶が{交叉|こうさ}する場として幾層もの時間を担い、読者の感覚に多重のリズムを生み出す[^4]。歴史は一度も論じられず、ただ地面の凹凸として置かれている。

とりわけ月影は、現前するものを照らしながら、同時にその輪郭を隠すという、相反する働きを負っている。作中で月の出る夜はわずか四度しかないが、その四度はいずれも物語の関節にあたる。月の光は、昼の庭では見えていたはずの{境|さかい}を消し、代わりに、昼には気づかれなかった影の輪郭を浮かび上がらせる。隠すことによって照らすというこの逆説[^5]は、喜和の沈黙のありようと正確に重なっている。

題名についても一言しておきたい。「沈黙の庭」は、庭が沈黙しているという意味にも、庭という場所で人が沈黙するという意味にも読める。作者はどちらとも決めていない。むしろ二つの読みが重なるところに、この作品の姿勢がある。沈黙は誰かひとりの持ち物ではなく、その場に居合わせた者が等しく分けもつ空気なのだ。

語り手である鈴も、この光の作法に従っている。彼女はしばしば視線を{逸|そ}らし、見たものについて明確な判断を留保する[^6]。噂を伝えるときも、鈴は決してどちらが本当かを言わない。読者はいらだちながら、やがて気づく。判断を差し控えることは、無関心の別名ではなく、他人の時間を{侵|おか}さないための作法なのだと。この静かな参加の構造こそが、静謐の庭を〈読む〉行為へと読者を転化させる。

物語の終わり近く、秋の台風で庭の大楓が倒れる。屋敷の屋根をかすめて根ごと横たわった幹は、久松がひとりで守りつづけてきた構図を一夜で壊してしまう。その翌朝、喜和がはじめて口をきく。だがその言葉は、鈴が長いあいだ待っていた告白でも弁明でもない。「井戸の水を汲んでおくれ」——それだけである。鈴は{桶|おけ}を提げて井戸へ行く。作者は、この短い一言に何の説明も添えない。

沈黙が破られたのに、何ひとつ明らかにならない。この結末を、読者はどう受け取ればよいのか。私は、ここで鈴が問わなかったことに注目したい。彼女は問える立場にいたし、問う理由もあった。それでも問わないことを選ぶ。最終場面、二人は倒木の切株に落ちる月の影を並んで見ている。こぼれた月影を拾うように、鈴は切株の面をそっと{撫|な}でる。庭は壊れたのではなく、別の形で続きはじめたのだと、読者はそこで知る。

遠見志津は一九一二年、のちに「沈黙の庭」の舞台となる苫緒からほど近い山国の町に生まれた。生家は小さな製糸工場を営んでいたが、その商いは志津が十代のうちに{傾|かたむ}いた。女学校を出た彼女は、町の印刷所に校正係として勤めることになる。以後四十年、書くことと生活とはほとんど交わらなかった。当時を知る人の話では、彼女は工場の帳場でよく庭木の図を描いていたという。

作家としての出発は遅い。戦後に同人誌「季刊燈心」へ加わり、最初の小説「{石蕗|つわぶき}の家」を発表したのは一九五三年、四十一歳のときである。生涯に発表した小説は十篇に満たず、文学賞とは終生無縁だった。職業作家であったことは一度もない。定年まで印刷所に通い、退職後は借家の狭い庭に{躑躅|つつじ}を植え、句会に出た。一九八〇年、苫緒の借家で死去。六十八歳であった。

遠見の文章は、形容を惜しむ。比喩はきわめて少なく、あってもすぐに引っ込められる。三十年にわたる校正の仕事が、彼女に「削る」訓練を与えたのだと見る向きもあるが、私はむしろ逆だと思う。削るために校正を選んだのではないか。彼女の原稿は、書き足した跡よりも消した跡のほうが多かったと、「季刊燈心」の編集を担った{塩尻|しおじり}{亮|りょう}が証言している。

形容を{惜|お}しむとはどういうことか。たとえば冒頭の一節である。「門を入ると、右手に{棕櫚|しゅろ}が二本あった。片方は枯れていた」。ただそれだけである。枯れた一本が何を暗示するのかは、どこにも書かれない。だが読み終えてから戻ってくると、この二本の木が屋敷の二人にほかならないことに、読者はいや応なく気づかされる。

塩尻の回想によれば、遠見は{合評|ごうひょう}会でほとんど発言しなかったという。他人の作品にも自作にも、感想を求められると「わかりません」と答えた。ただ一度だけ、若い同人が題材の悲惨さを誇るように語ったとき、静かに、それは書く人の悲惨ではないでしょう、と言ったと伝えられている。

遠見の名は、戦後文学のどの系譜にも収まりにくい。私小説の作家ではなく、社会派でもなく、前衛の実験にも関心を示さなかった。同人誌の仲間たちが政治と文学の関係をめぐって議論を{闘|たたか}わせているあいだ、彼女はひとり、庭の図面のような小説を書きつづけた。孤立していたというより、はじめから別の{畝|うね}を耕していたというほうが近いだろう。

本書には「沈黙の庭」のほか、初期の短篇「石蕗の家」、晩年の「{雨落|あまおち}」、未完に終わった長篇の断章「{夜半|よわ}の水」、そして随筆五篇を収めた。いずれも庭か水にかかわる。「石蕗の家」には、のちの喜和を思わせる無口な伯母が顔を出す。「雨落」は、雨だれの音だけで一家の三十年を書ききった小品である。とくに随筆「庭の記」は、「沈黙の庭」の下敷きとなった実景をたどることのできる貴重な一篇で、本篇と併せて読まれることを望みたい。

発表当時、この結末はしばしば「逃げ」と評された[^7]。戦争責任を主題に取りながら、作者は誰の罪も裁かず、真相さえ示さない。文学が告発の言葉を求められていた時代にあって、その姿勢は不徹底と映ったのだろう。だが半世紀を経て読み返すとき、私たちが打たれるのはまさにその不徹底である。裁くことをしない代わりに、この小説は、裁けないまま隣に住みつづけるという事態の重さを、ひとつも省略せずに引き受けている。

再評価の{端緒|たんしょ}は、意外にも小説の外から訪れた。一九九〇年前後、記憶と証言をめぐる議論が高まるなかで、語りえないことを語らないまま書くという方法があらためて注目され、「沈黙の庭」はその{稀|まれ}な達成として読み直されたのである。作品が変わったのではない。読む側の耳が、ようやく追いついたにすぎない。

一九九〇年代の終わりには、地方の小劇団が本篇を{脚色|きゃくしょく}し、{台詞|せりふ}をほとんど{削|そ}いだ舞台として上演している。原作の沈黙をそのまま舞台に置くという無謀な試みだったが、庭の音だけが続く七十分のあいだ、客席は最後まで静まりかえっていたという。

「沈黙の庭」の初出は、同人誌「季刊燈心」一九五六年冬号である[^8]。単行本は二年後の一九五八年、三日月坂出版から刊行された。初版千五百部、増刷はない。以後永く読みにくい状態が続いたが、没後三年の一九八三年、雲間書店が単行本未収録の短篇と随筆を加えて選集を編み、これに『月影拾遺』の名を与えた。書名は本篇結末の一句に{由|よ}る。

本文庫は、風灯社版『遠見志津作品集』第二巻を底本とし、雲間書店版の構成を受け継いでいる[^9]。旧仮名は現行の仮名遣いに改め、明らかな誤植を正した。ルビは初出誌のものを基本とし、読みにくい語に限って新たに付した。作中には今日の人権意識に照らして不適切な語がわずかに含まれるが、時代背景と作品の性質を考え、そのままとした。

いまこの文庫を手にした読者の多くは、戦争を知らない世代だろう。それでも、答えの出ない事柄と同じ屋根の下で暮らすことなら、誰にでも覚えがあるはずだ。「沈黙の庭」が古びないのは、それが戦争の小説だからではなく、隣にいる人を{裁|さば}きも{赦|ゆる}しもしないまま日々を続けるという、ごく尋常の作法を書いているからである。

読み終えた読者は、たぶんもう一度、最初の数ページに戻ることになる。あの荒れた庭の描写が、二度目にはまったく別のものに見えるはずだ。庭は、手を入れつづける者がいるかぎり庭でありつづける。この小説もまた、読み返す者がいるかぎり終わらない。四十年を経てなお新しい読者に手渡されることを、遠見志津は少しも期待していなかったに違いない。だからこそ、この静かな一冊は、いま手にした人のものである。
