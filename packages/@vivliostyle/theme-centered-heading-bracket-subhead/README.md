# @vivliostyle/theme-centered-heading-bracket-subhead

単段の事例解説集テーマ。中央寄せの番号付き標題見出しと副題・付記の階層表示、【】の隅付き小見出し、罫線表、末尾の「注」ブロックで組む。

## 使い方

```css
@import '@vivliostyle/theme-centered-heading-bracket-subhead';
```

## 原稿の書き方

標題番号 (h1)・解説の項番号 (h3の「一・二・三」)・注番号はすべてカウンタで生成する。原稿の見出しには番号を書かない。h1 ごとに改ページする。

```md
---
title: 契約の成立と意思表示 # 柱に出る章題
class: chapter # base の章カウンタを増やす (柱の「第N章」)
---

# 売買契約における錯誤と動機の表示  <!-- → 12  売買契約における… -->

<p class="subhead">甲山地方裁判所　令和6年3月19日判決</p>

<p class="meta">令和5年(ワ)第1234号　売買代金返還請求事件</p>

## 【事実の概要】 <!-- 隅付き見出しには番号を付けない -->

本文…[^1] <!-- 注は VFM の脚注記法。巻末に (1)(2)… で組まれる -->

## 【解説】

### 本判決の意義 <!-- → 一　本判決の意義 -->
```

注どうしの参照は空のアンカーで書く。`<a href="#fn12" data-ref="note"></a>` が「注(12)」になる (VFM は `[^12]` の定義に `id="fn12"` を振る)。

## カスタマイズ

`:root` で以下の変数を上書きしてカスタマイズできる。

| 変数 | 既定値 | 説明 |
| --- | --- | --- |
| `--vs-theme-centered-heading-bracket-subhead--font-display` | `'Shippori Mincho B1', ...` | 標題見出し(h1)と副題の表示書体 |
