# 汽車の窓 {#kisha}

昭和三十三年の春、私は{柏沼|かしわぬま}にある県立の高校に入った。青沼から汽車で二時間、朝は五時台の一番列車に乗らねばならない。通うのは無理だと父が言い、町はずれの{梅本|うめもと}さんの家に下宿することになった。

梅本のおばさんは{寡婦|かふ}で、二階の四畳半を学生に貸していた。夕飯はたいてい{一汁一菜|いちじゅういっさい}だったが、{沢庵|たくあん}だけは切れることがなかった。「勉強は、続くうちにしておきなさい」というのが口癖で、私が机に向かっていると、廊下を足音を{忍|しの}ばせて通った。

高校では図書室によく行った。青沼の家に本はほとんどなく、私はたぶん活字に{飢|う}えていたのだと思う。窓ぎわの席に座り、閉館まで機械や船の写真の載った本をめくった。読むというより、眺めていたに近い。

土曜の午後は汽車で家に帰った。窓は{煤|すす}で{曇|くも}っていて、袖でこすると、刈り入れの終わった田と、その先に光る海が見えた。トンネルを二つ抜けると青沼で、そこから先は海がずっと右手についてくる[^1]。

二年の冬、進路の話になった。担任は大学を勧めたが、私は口ごもった。姉はすでに{嫁|とつ}ぎ、家には両親と祖母がいる。学費のことを口にすると、父は「気にするな」と言い、そのあと長いこと黙っていた。あの沈黙の意味を、私は何十年も考えることになる。

結局、私は就職を選んだ。三年の秋、学校に届いていた求人票のなかから、計量器の部品をつくる会社を選んだ。理由をうまく説明することはできない。ただ「図面」という言葉に{惹|ひ}かれたのだと思う[^2]。

決めたことを父に伝えると、父は「そうか」と言っただけだった。母のほうが泣いた。祖母はもう寝たきりで、私が枕元で報告すると、聞こえたのかどうか、ゆっくりうなずいた。

卒業式の日、父は仕事を休んで柏沼まで出てきた。式のあいだ、いちばん後ろの壁ぎわに立っていた。帰りの汽車のなかで、父は「よくやった」とだけ言い、あとはずっと窓の外を見ていた。あのときの父の横顔は、いまも汽車の音といっしょに思い出す。

[^1]: 当時の柏沼線は一日<span class="tcy">11</span>往復。最終は午後八時前に青沼を出た。

[^2]: 求人票には「製図見習」とあった。実際に図面を引かせてもらえたのは、入社して三年目のことである。
