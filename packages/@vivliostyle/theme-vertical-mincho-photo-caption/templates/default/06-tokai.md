# 都会の灯 {#tokai}

昭和三十六年三月、私は青沼駅から夜行の列車に乗った。ホームには父と母、それに下宿の梅本のおばさんが来ていた。母は最後まで何も言わず、{汽笛|きてき}が鳴ってからようやく手を上げた。

勤め先は{青柳計器工業|あおやぎけいきこうぎょう}という、従業員が百人ほどの会社だった。計量器の部品をつくっていて、工場は川沿いの低い土地にあった。私は独身寮に入り、六畳をもう一人と分けて使った。

![入社して二年目、旋盤の前で](fig-workshop.svg)

はじめの一年は{雑役|ざつえき}のようなものだった。材料を運び、{切粉|きりこ}を掃き、機械に油を差す。{旋盤|せんばん}を触らせてもらえたのは、二年目の夏である。

はじめて自分で削った{真鍮|しんちゅう}の{軸|じく}は、いま思えばひどい出来だった。それでも{丹野|たんの}さんという先輩は、{罫書|けがき}の線と削り上がりを見比べて「線は読めてる」と言った。父の言った「木の癖を読め」という言葉を、そのとき久しぶりに思い出した。

三年目の春、私は寸法を読みちがえて、一日分の材料を{屑|くず}にした。工場長に呼ばれるものと思って{項垂|うなだ}れていたら、丹野さんは自分の作業を止めて、削り直しの段取りを組みはじめた。何も言われなかったことのほうが、叱られるよりこたえた[^1]。

その年の秋から夜学に通った。週に三度の製図の講習である。定規の使い方から始まって、半年で{投影図|とうえいず}が引けるようになった。工場から教室まで自転車で二十分、冬の川風はひどく冷たかったが、あのころが自分でいちばん伸びた時期だった気がする[^2]。

寮の窓からは、川のむこうに工場の灯が並んで見えた。眠れない夜、私はよくその灯を数えた。青沼の夜は暗く、灯といえば沖の{漁火|いさりび}くらいのものだったから、都会の灯はいつまで見ていても飽きなかった。

月に一度、家に手紙を書いた。書くことなどそう多くはない。それでも母は返事に、浜のことや祭りのことを、こまごまと書いてよこした。父からの便りは一度きりで、そこには「体を壊すな」とだけあった。

[^1]: 丹野さんは私が結婚した年に{郷里|きょうり}へ帰り、いまも年賀状のやりとりが続いている。

[^2]: 講習は月・水・金の午後七時から。受講料は会社が半分もってくれた。
