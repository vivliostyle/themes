# 潮風のなかへ {#shiokaze}

平成十四年の三月、私は四十一年勤めた会社を{退|しりぞ}いた。最後の日、若い者が寄せ書きをくれた。定規で丁寧に{枠|わく}が引いてあって、こういうところに図面をやった者の癖が出るのだと{可笑|おか}しかった。

その年の秋、私は一人で青沼へ帰った。駅は建て替えられ、木造の駅舎はコンクリートの小さな箱になっていた。改札はなく、切符を入れる{錆|さ}びた箱がぽつんと置かれているだけだった。

駅前の道は{舗装|ほそう}され、商店はほとんど閉まっていた。菓子屋も、自転車屋も、{床屋|とこや}も、みなシャッターが下りている。それでも道の曲がり具合だけは昔のままで、頭より先に足が道を覚えていた。

製材所の跡は、白線の引かれた広い駐車場になっていた。{土場|どば}のあったあたりに立ってみたが、もう何の見当もつかない。ただ、山から吹き下ろす風の向きだけが、記憶とぴたり合った。

{鴫浜|しぎはま}には{防潮堤|ぼうちょうてい}ができていた。灰色の壁が浜を{遮|さえぎ}り、階段を上らなければ海は見えない。上ってみると、海はやはりそこにあった。同じ色で、同じ音で、同じ匂いで[^1]。

生家はもうない。跡地には別の家が建っていて、私は道の反対側から{眺|なが}めただけで通り過ぎた。{枇杷|びわ}の木だけは残っていた。あんなに小さかった木が、いまは屋根より高い。

姉の君子は隣町にいる。訪ねると、{仏壇|ぶつだん}に父と母の写真が並んでいた。「あんたも、そろそろ書いておきなさい」と姉は言った。何を、と{訊|き}くと、「なんでも」と笑った。この本を書く気になったのは、たぶんあのときの一言のせいである[^2]。

いま私の手元に、一枚の写真がある。昭和三十二年ごろ、青沼駅の前で撮ったものだ。写っているのは中学生の私と、その後ろに立つ父である。二人とも、少し{眩|まぶ}しそうにしている。

あの日と同じ風が、いまも浜から吹いてくる。私はそれを、記憶と呼んでいる。

[^1]: 防潮堤は平成九年の完成。高さは五メートルほどある。

[^2]: 姉は現在も隣町に住み、月に一度は電話をよこす。
