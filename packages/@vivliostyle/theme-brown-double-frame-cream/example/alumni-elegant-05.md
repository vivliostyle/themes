# 編集後記

<img class="ornament" src="fig-ornament.svg" alt="" />

本号の編集にあたり、記念館の倉庫に眠っていた過去の会報を第一号から読み返しました。謄写版で刷られた初期の紙面には、当時の役員の手書きの文字がそのまま残っております。

紙も書体も変わりましたが、便りを届けたいという気持ちだけは、四十八号を数えた今も変わらないのだと思います。読み返しながら、名前だけを知っていた先輩方の輪郭が、少しずつ像を結んでいくようでした。

本号より、近況欄の掲載を卒業の年次順に改めました。世代のつながりが見えるようにという、昨年の読者の便りからいただいた思いつきです。ご意見をお寄せいただければ幸いです。

編集の作業は、月に一度、記念館の一室で四名の委員が持ち寄って進めております。原稿の整理から校正まで、いずれも手のかかる仕事ですが、届いたお便りを最初に読める役得もございます。委員を手伝ってくださる方を、いつでもお待ちしております。

<p class="signature">編集委員長　網代千鶴</p>
