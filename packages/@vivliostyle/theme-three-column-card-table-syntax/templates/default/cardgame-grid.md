# <span class="meta">CH1 — WORLD &amp; GLOSSARY</span>世界と用語 {#ch1}

# <span class="meta">CH2 — BASIC RULES</span>ゲームの基本 {#ch2}

対戦は、互いの管制塔を守りながら星脈路の支配権を奪い合う形で進む。各プレイヤーは40枚の山札を用意し、6つの区画からなる自陣にユニットを展開する。本章では準備から勝敗の確定までの手順を、段階ごとに番号を振って示した。ここで振った番号は第3章以降の裁定を引用するときの見出しとして用いる。
