# 辞書の余白と雨 {#essay-dictionary}

樋渡　慎之介

<aside class="sidebar">

**樋渡　慎之介**<br />（ひわたし　しんのすけ）<br />書誌学者

1954年生まれ。三十年あまりを大学図書館の目録係として過ごし、退職後も近代の辞書と読書の歴史を調べつづけている。著書に『語釈の余白』『引くという行為』。書きこみのある古書ばかりを集める癖があり、自宅の書棚は年ごとに通路が狭くなっている。月に一度、公民館で古い辞書を読む会を続けている。

</aside>

<span class="dropcap">雨</span>の日には古書店へ行く、というのが、長いあいだの習慣になっている。晴れた日に出かけない理由はないのだが、雨の日の店は客が少なく、紙の匂いが濃い。湿気を吸った本の匂いは、乾いた日のそれとは明らかにちがう。あれを嗅ぐために通っているのだろうと言われれば、強くは否定しにくい。

探すものは決めていない。棚のあいだを行きつ戻りつして、たいていは辞書の並びの前で足が止まる。古い辞書は、めったに読まれないまま古びる。読まれないので状態がよく、状態がよいのに安い。私のような人間には、都合のよいことばかりである。

辞書ばかり買っていると、家族には呆れられる。同じような本が何冊もあるように見えるらしい。実際には、版がちがえば別の本である。同じ語を引きくらべると、この二十年のあいだに世の中が何を大事にしなくなったかが、かなりの正確さでわかる。

先日、明治の終わりに出た小さな英和辞書を買った。三百円だった。持ち帰って開いてみると、余白のあちこちに、細い鉛筆の書きこみがある。訳語の脇に、別の訳語がひとつ、ふたつ。ときには短い例文らしきものまで添えられている。書き手は几帳面な人だったらしく、字はどれも同じ大きさで、傾きまで揃っていた。

辞書に書きこみをするのは、辞書を信じていない人である。というと言いすぎだが、少なくとも、そこに記された語釈で足りると思っていない人ではある。足りないと感じたときに、人ははじめて自分の言葉を余白に置く。あの細い鉛筆の跡は、そういう不満の記録なのだと思う。

不満の記録は、たいてい、本文よりもおもしろい。

書きこみの主がどんな人であったかを想像するのは、古書を買う楽しみのうちでも、いちばん行儀の悪いものだろう。それでも想像してしまう。この人は学生だったのか、教師だったのか。仕事で使っていたのか、それとも独りで学んでいたのか。書きこみは前のほうほど多く、後ろへ進むにつれてぱたりと減る。志の高さと持続の短さが、そのまま紙の上に出ている。私はどうも他人事とは思えない。

ひとつだけ、はっきり覚えている書きこみがある。ある語の訳語の下に、括弧をつけて、帰るところ、と書いてあった。辞書の訳語がまちがっているわけではない。ただ、その人にとっては、辞書の言葉では届かなかったのだろう。届かないと気づいたときに、人は自分の言葉を探しはじめる。辞書はそのための道具であって、答えそのものではない。

余白に書かれた言葉は、辞書に載ることがない。載る必要もない。あれはその人ひとりのために作られた語釈であって、他人が引くためのものではないからだ。それでも私は、こうして百年後にそれを引いている。引かれることを想定していない言葉を引くというのは、行儀は悪いが、なかなかに贅沢な読書である。

辞書は改訂のたびに語を捨てる。使われなくなった語を落とし、新しい語を入れる。当然の作業ではあるが、落とされた語には行き場がない。古い版を持っていれば会えるけれど、その古い版もいずれ捨てられる。言葉が死ぬというのは、辞書から消えることではなく、消えたことに誰も気づかなくなることなのだと思う。

目録係を長くやっていたので、捨てる側の仕事にも立ち会った。書庫が満杯になれば、どれかを外さなければならない。外す本を選ぶ日は、朝からずっと気が重かった。基準はある。基準はあるのに、最後の一冊はいつも基準では決まらなかった。

だから私は、雨の日に古書店へ行くのだろう。あそこには、行き場のなくなった語が、まだ紙のあいだで待っている。誰にも引かれないまま、ただ順番に並んで待っている。雨の音は、その待ち方によく似ている。急がず、やまず、誰に向かってでもなく降りつづけている。

三百円の辞書は、いま机の右手にある。私はまだ、余白に何も書いていない。
