# 米を研ぐ音のこと {#essay-rice}

苅田　ゆかり

<aside class="sidebar">

**苅田　ゆかり**<br />（かりた　ゆかり）<br />料理家・文筆家

1985年生まれ。惣菜店の台所で八年働いたのち、自宅で八人だけの料理教室をひらく。特別な材料も器具も使わない、家の台所のための献立を教えている。著書に『三合の暮らし』『鍋のふたを開けるまで』。手を動かしながら考えたことを書きとめた食まわりの随筆で知られ、地方紙のコラムを七年続けている。

</aside>

<span class="dropcap">米</span>を研ぐ音が好きです、と言うと、たいてい笑われます。それでも、あれは台所でいちばんいい音だと思うのです。最初のひとすくいはにごった重い音で、二度目にすこし軽くなって、三度目にはもう、しゃりしゃりという涼しい音になっている。ほんの短いあいだに三度も表情の変わるものは、家の中にそう多くありません。

母は、研いでいるあいだだけは何もしゃべりませんでした。ふだんはよくしゃべる人で、こちらが返事をしなくても勝手に話しているような人だったのに、あの三分だけは黙っている。子どものころの私はそれが不思議で、何度も台所をのぞきに行きました。母は水の音のほうが大事だという顔をして、こちらを見もしませんでした。

いまは無洗米というものがあって、研がなくてよいのだそうです。よくできていると思いますし、忙しい日には私も使います。ただ、使った日の夕飯は、なんとなく、はじまりの合図が抜けてしまったような気がするのです。味の問題ではありません。たぶん、時間の問題なのだと思います。研がずにすんだ三分は、いったいどこへ行ってしまったのでしょうか。

一日のうちで、手を動かしているのに何も考えなくてよい時間は、思っているよりずっと少ないものです。米を研ぐ三分は、その数少ないひとつでした。冷たい水に指を入れて、しゃり、しゃり、とやっていると、頭のなかにたまっていた雑音が、水と一緒に流れていきます。あとに残るのは、今日はこれを作ろう、というくらいの、ごく小さな考えだけです。

その三分がほしくて、私は今日も研いでいるのかもしれません。

小さな料理教室をひらいています。家庭の台所と同じ道具で、同じくらいの手順でつくる、ごくふつうの教室です。はじめて来られた方には、まず米を研いでいただきます。作り方をお教えする前に、その人の手つきを見ておきたいからです。乱暴な人はいません。ただ、急いでいる人と、そうでない人がいます。

いつだったか、生徒さんのひとりが、研ぎながら小さな声で、この音、思い出せなかったんです、とおっしゃいました。実家を出てから十年ちかく、ずっと無洗米だったのだそうです。忘れていたことにも気づいていなかった、と。そのあと、その方はずいぶん長く研いでいました。私は何も言わずに、鍋のほうを見ているふりをしていました。

研ぎ方に決まりはあるのですか、とよく聞かれます。あります、と答えることもできますし、ありません、と答えることもできます。手のひらの付け根で押すように、とか、水は三度で、とか、教わったことはいくつもあります。でも、その日の米の乾き具合も、水の冷たさも、鍋の大きさも毎日ちがうのですから、決まりのほうが先に折れてしまいます。折れたあとに残るものが、たぶん、その人の研ぎ方です。

母はもう台所に立ちません。去年、実家の流しの前に椅子を置きました。座ったままでも手は届きますが、水の勢いを弱くしないと跳ねてしまうので、音はずいぶん小さくなりました。それでも、研ぎはじめると母は黙ります。あの黙り方だけは、昔とまったく変わっていません。

実家に泊まった朝、二人で並んで研いだことがあります。母のほうが遅く、私のほうが先に終わってしまって、なんとなく手を止めて待ちました。待っているあいだ、しゃり、しゃり、という音が、ひとつぶんだけ台所に残っていました。あんなに小さな音なのに、部屋いっぱいに聞こえるのが不思議でした。

音は残らないものだと思っていました。写真も録音も残せますが、あの三度で変わっていく音は、たぶん、手のほうが覚えているのでしょう。だから教室では、作り方よりも先に手つきを見ます。習うより思い出していただくほうが早いことが、料理にはずいぶんたくさんあります。

今日も三合。水は、まだ冷たいままです。
