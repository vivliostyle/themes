# 砥石の水を替える {#essay-whetstone}

榛原　慶次

<aside class="sidebar">

**榛原　慶次**<br />（はいばら　けいじ）<br />木工家

1961年生まれ。二十歳で家具職人に弟子入りし、十年の修業のあと、山あいの町に小さな工房をひらく。椅子を中心とした受注制作のかたわら、道具と手仕事についての文章を書きつづけている。著書に『鉋の背中』『手が覚えていること』。工芸誌への寄稿多数。年に一度だけ、工房を開いて研ぎの会をひらいている。

</aside>

<span class="dropcap">砥</span>石は、使う前に水へ浸けておく。桶にそっと沈めると、石のふちから細かい泡が、いくつも列をつくって立ちのぼってくる。あれが止まるまでが待ち時間だ。三分か、五分か、時計で計ったことは一度もない。泡が出なくなれば、石が水を飲みおえたということで、こちらはそれだけの合図で充分に待てる。待たされている気は、ふしぎとしない。

道具の手入れは面倒でしょう、とよく言われる。面倒ではある。けれど、面倒だと思ったことは、あまりない。刃物を研ぐのは、明日の自分に宛てて短い手紙を書くようなものだからだ。今日のうちに研いでおけば、明日の自分が助かる。それだけの、ごく単純な取引である。返事はこないが、届かなかったこともない。

修業に入ったころ、親方に言われたことがひとつある。研ぐ音を聞け、というのだった。角度がうまく合っているときは、しゃり、しゃり、と揃った音がする。狂うと、音がわずかに濁る。手より先に耳が気づくのだ、と親方は言った。実際、そのとおりだった。目で見て直しているうちは、まだ研げていない。

もうひとつ、口うるさく言われたのは、水を替えろ、ということだった。研いでいるうちに、桶の水は鉄と石の粉で灰色に濁ってくる。濁ったままでも刃はつく。つきはするが、仕上がりがどこか鈍い。だから途中で一度、水を捨てて汲みなおす。手を止めるのが惜しいほど調子の出ているときほど、替えろ、と言われた。

若いころは、その意味がよくわからなかった。

自分の工房を持ってからは、水を替える回数が、修業のころより増えた。腕が上がったからではない。濁りに気づくのが早くなっただけのことだ。若いうちは、濁っていることにすら気づかない。気づかないまま研ぎつづけて、なんとなく切れない刃を作り、なんとなく納得のいかない椅子を納めて、それでも一日は終わってしまう。終わってしまうところが、いちばん厄介なのだと思う。

注文で椅子を作ることが多い。座面を削っていると、たまに、木のほうから止めどきを教えられることがある。手ざわりが、ふっと変わるのだ。そこで止めれば座り心地がよく、欲を出してもう一削りすると、たいてい失敗する。止めどきというのは、いつもこちらの都合とは関係のないところにあって、しかも、あらかじめ知らせてはくれない。

先日、若い人に、どうやって上達したのですかと聞かれた。うまい答えが浮かばず、水を替えることですかね、と言ってしまった。変な顔をされた。無理もない。私も二十歳のころ、同じことを言われて、まったく同じ顔をしたはずである。

その若い人は、自分の作ったものが思ったとおりにならない、とも言っていた。思ったとおりになるほうがめずらしい、と答えたら、いっそう困った顔をした。あのとき言えばよかったといまになって思うのは、思ったとおりにならないところにこそ、こちらの手の入る余地があるということだ。すべてが思いどおりになる材料があったとしたら、たぶん、面白くもなんともない。

いまはこう思っている。上達とは、たぶん、見えるものが増えることだ。同じ石、同じ刃、同じ手つきで研いでいても、以前は見えなかった濁りが見えるようになる。見えてしまえば、替えないわけにはいかない。だから手間は増える。増えた手間の分だけ、仕事は静かになっていく。速くはならない。静かになるのだ。

連れ合いには、あなたの仕事は片づけばかりだ、と言われる。たしかに、一日のうち実際に木を削っている時間より、研いだり、掃いたり、片づけたりしている時間のほうが長い。けれども、片づけの終わった台の上でしか、まっすぐな線は引けない。散らかった台の上で引いた線は、必ずどこかで曲がる。若いころは、それも腕のせいだと思っていた。

桶の水を捨てると、朝の光が底で一度だけ大きく揺れて、それから落ち着く。汲みなおした水は、驚くほど澄んでいる。この澄んだ水も、一時間後にはまた濁っているだろう。濁るとわかっていて汲むところが、この仕事のいちばん好きなところだ。
