# 夜の自販機、青い光 {#essay-vending}

箕輪　すず

<aside class="sidebar">

**箕輪　すず**<br />（みのわ　すず）<br />ライター

1996年生まれ。音楽情報サイトの編集部を三年で辞め、いまは夜のあいだに書く仕事をしている。深夜の散歩と、そのとき聴いていた曲について書いた連載「終電のあとで」をまとめた『夜がまだ長い』が最初の本。ライブ評のほか、街の音についての短い文章を各誌に寄せている。ほとんど昼に起きない。

</aside>

<span class="dropcap">夜</span>の一時ごろに家を出る。目的はない。角のコンビニまで行って、何も買わずに帰ってくることもある。歩きたいというより、部屋の中の空気に飽きた、という感じに近い。同じ空気を何時間も吸っていると、頭のかたちがだんだん部屋に合ってきてしまう気がする。

うちの近所に、道が二又に分かれるところがあって、その角に自販機が一台だけ立っている。まわりに店はない。街灯も一本きり。だから、その自販機がいちばん明るい。青みがかった白い光が、アスファルトを二メートル四方くらい、きれいな四角に切りとっている。

私はいつも、その四角の手前で足を止める。理由はうまく言えない。明るいところに入ると、自分が見られている気がするからかもしれない。暗いところは平気なのに、光のほうが落ち着かない。夜に強い人と弱い人がいるとしたら、私はたぶん、光に弱いほうの人だ。

そのくせ、あの光を見ないと帰れない。二又を左に行っても右に行っても家には着くのに、私は必ず自販機のある側を通る。眠れない夜にわざわざ確かめに行くものが、人にはひとつくらいあるのだと思う。私の場合は、それがあの四角だ。

先月、その自販機の前に、知らない人が座っていた。缶を持ったまま、飲むでもなく、ただ座っていた。私はいつもの位置で足を止めて、どうしようかと少し迷って、結局そのまま通りすぎた。すれちがうとき、その人は顔を上げなかった。こちらも見なかった。それでいいと思った。

夜は、そういうことができる時間だ。

翌週も、その人はいた。同じ時間、同じ位置。今度は缶を持っていなかった。三度目に見かけたとき、さすがに気になって、少しだけ歩調をゆるめた。すると向こうが先に、こんばんは、と言った。ふつうの声だった。私も、こんばんは、と返した。それだけで、あとは何も話さずに通りすぎた。

四度目からは、こんばんは、が習慣になった。名前も、どこに住んでいるのかも知らない。知りたいとも思わない。夜に会う人のことを昼に考えると、たいてい、うまくいかなくなる気がする。

歩くときは、いつもイヤホンをしている。曲は決めていない。決めていないのに、この道ではこの曲、というのが自然に決まってしまう。二又の手前ではだいたい同じ曲が鳴っていて、自販機の光が見えるあたりで、ちょうど間奏に入る。何度も歩いているうちに、道と曲が勝手に縫い合わされたのだと思う。

一度だけ、イヤホンを外して歩いてみたことがある。曲がないと、道はずいぶん長かった。自分の靴の音と、遠くの車の音と、どこかの家の換気扇の音。それだけしかないのに、うるさいと感じた。音楽は、たぶん、静けさを聞かないためにあるのだと思った。それ以来、外していない。

あの夜から、私は四角の中に入るようになった。入っても、べつに何も起こらない。ただ、光の中では自分の影が濃くなる。濃い影を連れて歩くのは、思っていたより悪くない。暗いところにいると、影はどこにもない。ないほうが自由な気もするけれど、たぶん、少しさびしい。

自販機は、去年から一本だけ売り切れのランプがついたままだ。誰かが補充を忘れているのか、もう作られていない飲みものなのか、わからない。私はそのボタンを押したことがない。押さないまま、毎晩その前を通る。押さないでおくのが、なんとなく、この道との約束みたいになっている。

その人は、先月から来ていない。引っ越したのかもしれないし、夜に出る用事がなくなったのかもしれない。いなくなった人を心配できるほど、私たちは知り合いではなかった。ただ、四角の中を通るとき、少しだけ横に寄って歩く癖がついた。

今夜も出る。たぶん、何も買わない。
