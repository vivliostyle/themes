# @vivliostyle/theme-circled-number-two-column

2段組のコンパクトなレシピ本向けテーマ。左右の段に1品ずつを完結配置し、アクセントカラーを丸数字見出し・データバー・表罫に反復する実用的なレシピ紙面を組む。

## 使い方

```css
@import '@vivliostyle/theme-circled-number-two-column';
```

## 原稿の書き方

- `## 品名` が 1 品で、段の頭から始まる。品番は見出しの順序から自動で振られるので、見出しに番号を書かない。品数のぶんだけ段が増え、段が尽きればページが増える。
- コラムなどレシピ以外の読み物は閉じ `#` を付けて `## 見出し ##` と書く。VFM がセクションに包まないので、番号バッジが付かず、段をまたいで流れる。
- 調理時間・分量・保存期間のデータバーは `<div class="stat-block">` に 4 項目のリストを書く。
- 手順の番号 (`ol`) はカウンタが振る。項目のあいだに空行を入れない (空行を入れると各項目が段落になり、番号が本文と別行に落ちる)。

## カスタマイズ

`:root` で以下の変数を上書きしてカスタマイズできる。

| 変数                                | 既定値                                             | 説明                                         |
| ----------------------------------- | -------------------------------------------------- | -------------------------------------------- |
| `--vs-theme-circled-number-two-column--color-accent`          | `--vs-color-foreground-alt` と同じ | 丸数字見出し・データバー・表罫のアクセント色 |
