## 詰める順番はごはんから ##

お弁当の出来は、詰める順番でほとんど決まります。大きいものから置いて位置を先に決め、小さいおかずを最後に差し込むと、片寄りのない一箱になります。手を動かす前に、箱のどこに何を置くかを決めてしまうのが近道です。

1. **ごはんを詰めて冷ます**　温かいうちに平らに詰め、ふたを開けたまま完全に冷ます。湯気が残ったままふたをすると水滴がたまる。
2. **主菜を立てて置く**　いちばん大きいおかずを箱の高さいっぱいまで立てて詰め、全体の位置を決める。
3. **副菜はカップに入れる**　味や汁気が移りやすいものはカップに入れ、主菜のとなりに寄せる。
4. **すきまを埋める**　残った谷間に小さなおかずを差し込み、表面が平らになるようにならす。
5. **彩りを最後に足す**　全体を見て足りない色をひとつだけ加える。入れすぎると散らかって見える。
6. **傾けて確かめる**　ふたをする前に箱を軽く傾け、動くところがあれば詰め直す。

ごはんの量は箱の容量のおよそ4割が目安です。おかずを詰めきれないときは、ごはんを減らすより箱を大きくしてください。

| 弁当箱の容量 | ごはんの量 |
| ------------ | ---------- |
| 500ml        | 180g       |
| 650ml        | 220g       |
| 800ml        | 260g       |

詰め終わったら、ふたをする前にもう一度全体にさわって温度を確かめます。ごはんもおかずも人肌より冷たくなっていれば、ふたの裏に水滴はつきません。

## すきまをつくらない小わざ ##

すきまが残ると、持ち歩くうちに中身が動いて崩れます。おかずを足すより、いま入っているものの置き方を変えるほうが早い場合もあります。すきまは横より上下にできていることが多いので、まず高さを見てください。

1. **葉物を仕切りに使わない**　水気の出る葉物は時間がたつと縮み、あとからすきまができる。仕切りはカップかバランで。
2. **丸いおかずは向きをそろえる**　うずら卵やミートボールは平らな面を上にすると、転がらず表面もそろう。
3. **平たいおかずは立てる**　卵焼きや焼き魚は切り口を上にして立てると高さが出て、上下のすきまが消える。
4. **細いものは束ねる**　いんげんやちくわは3〜4本まとめて同じ向きに置くと、面ができてすきまが減る。
5. **カップの中も満たす**　カップに余白があると中身が動く。量が少ないおかずは小さいカップに移す。
6. **最後は乾いたものを**　すきま埋めには汁気のないおかずを選ぶ。ラペやピクルスは必ず汁気をきってから。

それでも動くときは、詰めたあとにキッチンペーパーを一枚かぶせ、ふたで軽く押さえてから外すと落ち着きます。すきま埋め用のおかずは、次の量を目安に用意しておくと迷いません。

| すきま埋めのおかず | 目安    |
| ------------------ | ------- |
| ちくわの磯辺揚げ   | 2切れ   |
| うずら卵のピクルス | 2個     |
| ブロッコリー       | 1房     |
| にんじんのラペ     | 大さじ2 |

## 作り置きは冷ますまでが調理 ##

作り置きが最後まで持つかどうかは、加熱よりも冷まし方と扱い方で決まります。次の6つを守れば、日曜に作ったおかずを金曜まで無理なく使い回せます。特別な道具はいりません。

1. **中心まで火を通す**　肉や魚は中心の色が変わるまで加熱する。半生のまま保存しない。
2. **浅い容器で早く冷ます**　深い容器は中心が冷めにくい。バットや浅い保存容器に広げ、30分以内に粗熱を取る。
3. **容器は乾かしてから使う**　洗ったあとの水滴が残っていると傷みが早い。清潔なふきんで拭いてから詰める。
4. **取り分けは清潔な箸で**　食べかけの箸を保存容器に入れない。取り分け用の箸を一膳決めておく。
5. **味つけは少し濃いめに**　塩、しょうゆ、酢を通常より1割増やすと日もちがよくなる。
6. **作った日を書いておく**　ふたにテープで日付を書き、古いものから使いきる。

各レシピの保存日数は、冷蔵4℃前後で保存した場合の目安です。夏場や持ち歩く時間が長い日は、1日短く見積もってください。

| 粗熱の取り方   | 目安時間 |
| -------------- | -------- |
| バットに広げる | 20分     |
| 保存容器のまま | 60分     |
| 保冷剤にのせる | 10分     |

## 冷凍と解凍のつきあい方 ##

冷凍しておいたおかずは、朝そのまま詰めれば保冷剤の代わりにもなります。ただし解凍したときに水が出るものは、詰める前にひと手間が必要です。冷凍室で1か月を超えたものは、味も食感も落ちます。

1. **1食分ずつ小分けにする**　カップに1食分を入れて金属のバットにのせ、一気に凍らせる。
2. **水気は凍らせる前に絞る**　ゆで野菜や和えものは、水気を絞ってから冷凍する。
3. **平らにして凍らせる**　厚みをそろえて薄く広げると、凍るのも解けるのも早い。
4. **凍ったまま詰める**　朝、凍ったままカップごと詰めれば、昼までに自然解凍される。
5. **揚げものは温め直す**　唐揚げや磯辺揚げはトースターで3分温め、冷ましてから詰める。
6. **中身と日付を書く**　凍らせると見分けがつかない。ふたに書いてから冷凍室へ。

| 冷凍に向かない食材 | 理由       |
| ------------------ | ---------- |
| きゅうり、レタス   | 水が出る   |
| じゃがいも         | ぼそつく   |
| ゆで卵の白身       | ゴムになる |
| マヨネーズ和え     | 分離する   |

これらは冷蔵で2〜3日のうちに使いきる献立に回します。凍らせてよいかどうかは、水分の多さで見分けてください。

## 彩りは三色、白は仕上げ ##

茶色いおかずばかりでも、赤・緑・黄のどれかがひとつ入るだけで印象が変わります。まずは下の表から、その日の冷蔵庫にあるものをひとつずつ選んでください。白は全体を締める仕上げの色です。

| この章のおかず     | 色  |
| ------------------ | --- |
| 卵焼き、かぼちゃ煮 | 黄  |
| ブロッコリー       | 緑  |
| にんじんラペ       | 赤  |
| れんこん、うずら卵 | 白  |

1. **同じ色を隣に置かない**　茶色が並ぶと重く見える。あいだに緑のカップをひとつはさむ。
2. **面積は主菜をいちばん大きく**　色を散らしすぎると散漫になる。彩りは主菜の脇に小さく置く。
3. **赤は最後に足す**　ミニトマトや赤い漬けものは、詰め終わってから空いた場所に入れる。
4. **迷ったら緑を足す**　どの色とも合い、量の調整もきく。ゆでたブロッコリーを常備しておくと安心。
5. **ごまと青のりで締める**　全体がぼやけたら、白ごまか青のりを少しふる。輪郭が出て引き締まる。

三色そろえるのが難しい日は、黄と緑の二色だけでも十分です。色数を増やすことより、同じ色を離して置くことのほうが効きます。

## 一週間の組み立て例 ##

主菜は日曜にまとめて仕込み、副菜は2品を交互に使い回します。すきま埋めのおかずは日もちがするので、月曜に作れば金曜まで持ちます。同じおかずが2日続かないように並べるのがコツです。

1. **月**　鶏むねの青のり唐揚げ／ブロッコリーのおかかバター／卵焼き
2. **火**　鮭のみそマヨ焼き／にんじんとツナのラペ／ちくわの磯辺揚げ
3. **水**　豚こまとピーマンのしょうが炒め／かぼちゃのレモン煮／うずら卵のカレーピクルス
4. **木**　卵焼き／れんこんのきんぴら／にんじんとツナのラペ
5. **金**　冷凍しておいた唐揚げ／かぼちゃのレモン煮／ちくわの磯辺揚げ

金曜は凍らせておいた主菜を凍ったまま詰めれば、朝は副菜を入れ直すだけで仕上がります。木曜までに使いきれなかった副菜は、卵焼きに混ぜ込むと無駄になりません。

| 日曜の仕込み    | 時間 |
| --------------- | ---- |
| 鶏むね肉の下味  | 10分 |
| 主菜を2品つくる | 40分 |
| 副菜を2品つくる | 30分 |
| 冷凍用に小分け  | 10分 |
