## ふんわり卵焼き

![花形の皿に盛った卵焼き3切れ](fig-tamagoyaki.svg)

<div class="stat-block">

- ![調理時間](icon-time.svg) **10<span>分</span>**
- ![分量](icon-serving.svg) **2<span>人分</span>**
- ![冷蔵保存](icon-fridge.svg) _冷蔵_ **3<span>日</span>**
- ![冷凍保存](icon-freezer.svg) _冷凍_ **2<span>週間</span>**

</div>

| 材料（2人分） | 分量       |
| ------------- | ---------- |
| 卵            | 3個        |
| 砂糖          | 大さじ1    |
| しょうゆ      | 小さじ1    |
| みりん        | 小さじ1    |
| 塩            | ひとつまみ |
| サラダ油      | 適量       |

1. ボウルに卵を割り入れ、砂糖、しょうゆ、みりん、塩を加えてよく溶きほぐす。
2. 卵焼き器を中火で熱し、薄く油をひく。卵液の1/3量を流し入れ、半熟状になったら手前に巻く。
3. あいた部分に再び油を薄くひき、卵液の1/3量を流し入れて巻く。これをもう一度繰り返す。
4. 形を整え、弱火で1〜2分焼く。食べやすい大きさに切る。

## 鶏むねの青のり唐揚げ

![皿に盛った青のり唐揚げとレモン](fig-karaage.svg)

<div class="stat-block">

- ![調理時間](icon-time.svg) **10<span>分</span>**
- ![分量](icon-serving.svg) **2<span>人分</span>**
- ![冷蔵保存](icon-fridge.svg) _冷蔵_ **3<span>日</span>**
- ![冷凍保存](icon-freezer.svg) _冷凍_ **2<span>週間</span>**

</div>

| 材料（2人分）      | 分量        |
| ------------------ | ----------- |
| 鶏むね肉（皮なし） | 1枚（250g） |
| 酒                 | 大さじ1     |
| しょうゆ           | 大さじ1     |
| おろししょうが     | 小さじ1     |
| 片栗粉             | 大さじ3     |
| 青のり             | 小さじ1     |
| サラダ油           | 適量        |

1. 鶏肉はそぎ切りにして、酒、しょうゆ、おろししょうがをもみ込み、10分ほど置く。
2. ポリ袋に片栗粉と青のりを入れて混ぜ、鶏肉を加えてまぶす。
3. フライパンに1cmほどの油を入れて中火で熱し、鶏肉を並べる。
4. 表面がカリッときつね色になるまで揚げ焼きにする。油をきって器に盛る。

| ------------- | ------------- |

</div>

| 材料（2人分）  | 分量    |
| -------------- | ------- |
| 豚こま切れ肉   | 150g    |
| ピーマン       | 3個     |
| おろししょうが | 小さじ1 |
| しょうゆ       | 大さじ1 |
| 酒             | 大さじ1 |
| 砂糖           | 小さじ1 |

## かぼちゃのレモン煮

![皿に盛ったかぼちゃのレモン煮](fig-kabocha.svg)

<div class="stat-block">

- ![調理時間](icon-time.svg) **20<span>分</span>**
- ![分量](icon-serving.svg) **4<span>人分</span>**
- ![冷蔵保存](icon-fridge.svg) _冷蔵_ **4<span>日</span>**
- ![冷凍保存](icon-freezer.svg) _冷凍_ **3<span>週間</span>**

</div>

| 材料（4人分） | 分量          |
| ------------- | ------------- |
| かぼちゃ      | 1/4個（300g） |
| 水            | 150ml         |
| 砂糖          | 大さじ2       |
| レモン汁      | 大さじ1       |
| 塩            | ひとつまみ    |

1. かぼちゃは種とわたを除き、3cm角に切る。皮を所々そぎ落とす。
2. 鍋に皮を下にして並べ、水、砂糖、塩を加える。
3. 落としぶたをして中火で10分、竹串がすっと通るまで煮る。
4. レモン汁を加えてひと煮立ちさせ、火を止めて冷ましながら味を含ませる。

</div>

| 材料（4人分） | 分量    |
| ------------- | ------- |
| れんこん      | 200g    |
| 赤唐辛子      | 1/2本   |
| ごま油        | 小さじ2 |
| 酒            | 大さじ1 |
| しょうゆ      | 大さじ1 |
| 砂糖          | 小さじ2 |
| 白いりごま    | 少々    |

- ![調理時間](icon-time.svg) **10<span>分</span>**
- ![分量](icon-serving.svg) **2<span>人分</span>**
- ![冷蔵保存](icon-fridge.svg) _冷蔵_ **2<span>日</span>**
- ![冷凍保存](icon-freezer.svg) _冷凍_ **2<span>週間</span>**

</div>

| 材料（2人分） | 分量    |
| ------------- | ------- |
| ちくわ        | 4本     |
| 小麦粉        | 大さじ3 |
| 水            | 大さじ2 |
| 青のり        | 小さじ1 |
| サラダ油      | 適量    |

## うずら卵のカレーピクルス

![皿に盛ったうずら卵のカレーピクルス](fig-uzura.svg)

<div class="stat-block">

- ![調理時間](icon-time.svg) **10<span>分</span>**
- ![分量](icon-serving.svg) **4<span>人分</span>**
- ![冷蔵保存](icon-fridge.svg) _冷蔵_ **5<span>日</span>**
- ![冷凍保存](icon-freezer.svg) _冷凍_ **×**

</div>

| 材料（4人分）      | 分量      |
| ------------------ | --------- |
| うずらの卵（水煮） | 12個      |
| 酢                 | 大さじ3   |
| 水                 | 大さじ3   |
| 砂糖               | 大さじ1   |
| 塩                 | 小さじ1/3 |
| カレー粉           | 小さじ1/2 |

1. 小鍋に酢、水、砂糖、塩、カレー粉を入れ、中火で砂糖が溶けるまで温める。
2. 火を止めて粗熱を取る。
3. 保存容器にうずらの卵を入れ、2を注ぐ。
4. 冷蔵庫で3時間以上漬け、汁気をきってから詰める。
