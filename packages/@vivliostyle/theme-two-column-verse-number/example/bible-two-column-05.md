## 灯と沈黙

灯は語らず、ただ闇の際に立つ。光を負う者はおのれを照らさず、遠き岸のためにのみ燃ゆ。心して聞け、静けさのうちに灯される者の名を。おのが焔を誇る者は速やかに燃え尽き、焔を隠して守る者は夜のいたるまで残る。

<a id="s12-2"></a>昔、丘のうえに住む者ありき。夜ごと火を絶やさず、朝ごとに灰をあらためたり。人その理由を問えども、彼は答えず、ただ黙して薪をくべたり。答えなき業のうちにこそ、まことの祈りは宿る<span class="footnote">「答えなき業」について。祈りは言葉にさきだつとする古き教えによる。<span class="meta">cf. 静謐の書 <a href="bible-two-column-02.html#s07-12" data-ref="verse"></a></span></span>。

沈黙は空しきにあらず。満ちたる器の、こぼれざるがゆえの静けさなり。言葉おおき者はしばしば渇き、黙して立つ者はしばしば潤う。ゆえに賢き者は、語る前に一度、内なる水面を見るなり。

<a id="s12-4"></a>道を求むる者よ、灯をかかげて走るなかれ。光は歩みの速さによらず、掲ぐる手の確かさによる<span class="footnote">「掲ぐる手の確かさ」は、信の持続を指す隠喩とされる。<span class="meta">cf. 沈黙の巻 <a href="bible-two-column-07.html#c03-5" data-ref="verse"></a></span></span>。急ぐ焔はおのれを消し、静かなる焔は夜を渡る。

われ汝に告ぐ、暗きを呪うなかれ。暗きもまた光の座なればなり。星は昼に隠れ、夜にあらわる。ゆえに闇をおそるる者は、いまだ星を知らざる者なり。おのが夜を受け容れよ、そこにこそ汝の星は昇らん。

<a id="s12-6"></a>火を守る者は孤独なり。されどその孤独は、世をはなるる孤独にあらず。むしろ世の縁に立ちて、帰り来る者を待つ孤独なり<span class="footnote">「世の縁」とは、隠棲とまじわりの境をいう。<span class="meta">cf. 静謐の書 <a href="bible-two-column.html#s01-24" data-ref="verse"></a></span></span>。待つことは、業のうちの最も重き業なり。

問う者ありき、「灯はたがために燃ゆるや」と。答えていわく、「たがためにもあらず。ただ迷わずして帰る者のために、そこにあれば足る」と。求めずして与うる光こそ、まことの光なり。

静けさをおそれよ、されど遠ざかるなかれ。静けさは審く者にあらず、証しする者なり。汝の内なる焔を、静けさの前にさらせ。そこにこそ、汝のはかりは定まる。喧しきに逃るる者は、おのれをも失うなり。

<a id="s12-9"></a>光は消ゆ、また点る。これを飽かずくり返しうる者のみ、灯を継ぐに足る<span class="footnote">灯を継ぐ者の資格。反復のうちに忠実を見る思想による。<span class="meta">cf. 静謐の書 <a href="bible-two-column-03.html#s09-2" data-ref="verse"></a></span></span>。継ぐとは、おなじ火を絶やさぬこと。あたらしき火を誇ることにあらず。

見よ、夜は長し。されど長き夜も、ひとつの灯を消すことあたわず。消えたるは、まもる手を離れし灯のみ。ゆえに手を離すなかれ、まどろむとも。灯は眠る者の傍らにも、なお静かに燃ゆ。

<a id="s12-11"></a>おのれを量らんとする者は、まず静けさに入れ。喧しきなかに己は見えず、静けさのなかにのみ、影はその丈を示す<span class="footnote">「影はその丈を示す」。自己審査の隠喩とされる。<span class="meta">cf. 夜半の詩 <a href="bible-two-column-08.html#y04-17" data-ref="verse"></a></span></span>。影を恥じるなかれ、影あるは光に近きしるしなればなり。

汝ら、みずからの灯を数うるなかれ。数うる者はやがて競い、競う者はやがて曇る。灯はその数によらず、その澄みによりて夜を照らす。数えらるる光は、すでに光にあらず。おのが手にある一つを、まず正しく点せ。

<a id="s12-13"></a>隣人の焔の小さきをあざけるなかれ。小さき焔もまた、汝の見ざる隅を照らせり<span class="footnote">「見ざる隅」。各人の光には及ばぬ領域があるとする教え。<span class="meta">cf. 灯明譚 <a href="bible-two-column-09.html#t02-9" data-ref="verse"></a></span></span>。おのが光の届かぬところを、たれかの灯が守りてあり。

油を惜しむなかれ、されど注ぎ過ぐるなかれ。過ぐる油は焔をあふれさせ、惜しむ油は焔を細らす。中庸とは量にあらず、注ぐ手のためらいなきをいうなり。

<a id="s12-15"></a>器を洗え、日ごとに。煤は音もなく積み、やがて光をくもらす。おのが内の煤を見ざる者は、世の暗きを灯のとがとなすなり。まず拭え、しかるのちに嘆け。

<a id="s12-16"></a>灯を人に貸すことを恐るるなかれ。分かちても焔は減らず、かえって夜の広さを縮む。惜しみて抱く者のみ、ひとりの闇にとどまるなり。分かつ手は、みずからの芯をも整うるなり。

さればゆけ、しずかに、灯を負いて。汝の道は照らされずとも、汝ののちを来る者の道は照らされん。これ、灯を負う者のさだめなり。夜を越えて、灯はまた誰かの手に継がれん。

終わりに告ぐ。汝が灯、いつか消ゆべし。されど汝が点したる焔のいずれかは、なお遠き丘に燃えん。これを知る者は、消ゆるを憂えず、ただ今宵の芯を切るなり。
