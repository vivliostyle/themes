## 器と沈黙

器を語らん。器は容るるものにして、みずから満たざるものなり。満たさんとする器は、いつか内より割る。割れて後、はじめておのが厚さを知る。

水を汲む者、まず器を空にせよ。前の水を惜しむ者は、新しき水を得ず。惜しみたる水はやがて濁り、濁りたる水は器をも害す。

空しきを恐るるなかれ。空しきは欠けにあらず、招きなり。招かざる器のもとに、たれも来たらず。来たらざるを、人はしばしば静けさと取りちがう。

器に厚薄あり。厚き器は割れがたく、また温まりがたし。薄き器は早く応え、また早く傷つく。いずれを善しとも言わず、ただおのが厚さを知れとのみ言う。

<a id="s07-5"></a>器に響きあり。空しきときは高く鳴り、満ちたるときは鳴らず。鳴らざるを死とするなかれ、満ちたるしるしなればなり<span class="footnote">器の響きを心の状態にたとえる譬え。以下三節に及ぶ。<span class="meta">cf. 沈黙の巻 <a href="bible-two-column-07.html#c03-2" data-ref="verse"></a></span></span>。

されど鳴らざる器のうちにも、二種あり。満ちて鳴らざる器と、割れて鳴らざる器と。外より見て、これを分かつことあたわず。

分かつは、注ぐときのみ。ゆえに器は、注がるるまでおのれを知らず。試みは罰にあらず、器の音を聞く時なり。

人もまたしかり。おのが器を知らんとする者は、静けさに坐して待つべからず。まず、たれかの渇きの前に立て。立ちて後、汝の底は汝に示さる。

<a id="s07-9"></a>割れたる器を捨つるなかれ。継ぎたる跡は、割れざる肌より水を漏らさぬことあり<span class="footnote">「継ぎたる跡」。傷を経たる者の強さを説く。<span class="meta">cf. 灯明譚 <a href="bible-two-column-09.html#t02-6" data-ref="verse"></a></span></span>。継ぎ目は弱きの跡にして、また越えたるの跡なり。

継ぎ目を隠す者は、二たび割る。継ぎ目を見する者のもとには、おなじく割れたる者の集まり来たる。集まりて後、その部屋は器の蔵となる。

沈黙は器の内側なり。外より計られず、されどそこにのみ、容るるはたらきあり。内側を持たぬものを、器とは呼ばず。

<a id="s07-12"></a>ゆえに祈りは言葉にさきだつ。言葉は器の口にすぎず、内なる静けさこそ容るる場なり。答えなき業のうちにまことの祈りの宿るは、これによる<span class="footnote">本節は「答えなき業」の典拠とされる。<span class="meta">cf. 静謐の書 <a href="bible-two-column-05.html#s12-2" data-ref="verse"></a></span></span>。

口の広き器はこぼしやすく、口の狭き器は注ぎ入れがたし。ほどを知るは、幾夜の失いによる。失わずして得たるほどは、いつも他人のほどなり。

器を拭うは、水のためにあらず、次に来たる者のためなり。おのがために拭う者は、しばしば拭き残す。見らるる面のみ磨かるるは、これによる。

<a id="s07-15"></a>汝が器、いつか土に還らん<span class="footnote">「土に還らん」。器の有限を説く句。夜半の詩にも同じ言い回しあり。<span class="meta">cf. 夜半の詩 <a href="bible-two-column-08.html#y04-3" data-ref="verse"></a></span></span>。されど容れたる水は、すでにたれかの渇きとなりてあり。かたちは失せ、はたらきは残る。

器を誇るなかれ、水を誇るなかれ。ただ、渡す手を静かにせよ。静かなる手より受くる水のみ、こぼれずして届く。

大いなる器を求むる者あり。求めて得たる後、これを満たすに幾年を要すかを知らず。年を惜しむ者は、小さき器にて足れ。

小さき器を恥ずる者あり。されど旅に負わるるは、いつも小さき器なり。持ち運ばるることもまた、器の徳なり。

器に名を刻む者あり。刻みたる名は水の味を変えず、されど注ぐ者の手を、しばしば重くす。

二つの器を並べて、いずれ美しと問うなかれ。問わるるは器にして、渇く者にあらず。渇く者は、ただ近きを取る。

器を並べ替うるに一夜を費やす者あり。その夜、たれの渇きも癒えざりき。整えは業の初めにして、業そのものにあらず。

空の器を、卓のうえに伏せて置くなかれ。伏せたる器は塵をこそ防げ、たれをも招かず。口を上に向けて置け、たとえ幾夜、何も入らざるとも。

器のうちに、たれかの落としたる小石あらん。水を注ぐ前に、まずこれを出せ。石は水を濁らせず、ただ水の座を占むるのみ。占めらるる分だけ、汝は渇く者を待たすなり。

器を人に贈るとき、水を満たして渡すなかれ。空にして渡せ。何を容るるかは、受くる者の選ぶところなり。

されば器を作れ、静かに。作りて、置け。置きたる器のもとに、汝の知らぬ渇きの来たる夜あらん。
