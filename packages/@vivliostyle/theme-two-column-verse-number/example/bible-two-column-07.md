## 掲ぐる手

沈黙は言葉の欠けにあらず。いまだかたちを取らざる言葉の、みなぎりなり。欠けと満ちとは、外より同じく見ゆ。

<a id="c03-2"></a>満ちたる器の鳴らざるごとく、満ちたる心は語らず。鳴らざるを空しとする者は、耳のみにて量る者なり<span class="footnote">器の響きの譬えを承く。<span class="meta">cf. 静謐の書 <a href="bible-two-column-02.html#s07-5" data-ref="verse"></a></span></span>。

語ることを禁ずるにあらず。語る前に一度沈むことを説くなり。沈まざる言葉は水面の泡にして、生まれたる場を出でず。

沈黙のうちにて、人ははじめておのが声を聞く。喧しきなかに聞こゆる声は、たいてい他人の声なり。

<a id="c03-5"></a>灯を掲ぐる手は、しばしば震う。震いを恥ずるなかれ。確かさとは震わざることにあらず、震いてなお下ろさざることなり<span class="footnote">「掲ぐる手の確かさ」の典拠。信の持続を説く。<span class="meta">cf. 静謐の書 <a href="bible-two-column-05.html#s12-4" data-ref="verse"></a></span></span>。

一たび下ろしたる手を、ふたたび挙ぐるは重し。ゆえに下ろす前に、しばし待て。待ちて後もなお重ければ、下ろしてよし。

待つことは、何もせざることにあらず。待つ者の内にては、絶えず選びの行われてあり。外より見えざるのみ。

沈黙を武器とする者あり。それは沈黙にあらず、装いたる刃なり。刃は静かなれど、静けさにあらず。

<a id="c03-9"></a>守りには、かならず風の道を残せ。息を絶ちて守られたるものは、守られたるかたちのまま死す<span class="footnote">過剰なる庇護を戒む。初章の「覆い」の教えを承く。<span class="meta">cf. 静謐の書 <a href="bible-two-column.html#s01-14" data-ref="verse"></a></span></span>。

助けを求むる声は、しばしば沈黙のかたちを取る。ゆえに耳のみをもて聞くなかれ。目をもて、間をもて聞け。

<a id="c03-11"></a>渡さるる日は選べず。備えは日を待たず、日もまた備えを待たず。ゆえに備えとは、常に半ばにて足ることをいう<span class="footnote">継承の突然を説く。<span class="meta">cf. 静謐の書 <a href="bible-two-column-03.html#s09-9" data-ref="verse"></a></span></span>。

<a id="c03-12"></a>省みは、熱きうちに行うなかれ。熱きうちの省みは裁きとなり、冷めてのちの省みのみ道となる<span class="footnote">日を置きて省みる作法の典拠。<span class="meta">cf. 静謐の書 <a href="bible-two-column-06.html#s13-14" data-ref="verse"></a></span></span>。

沈黙の長きを、言葉にて埋むるなかれ。埋めたる沈黙は、あとにて二倍の長さとなりて返る。

二人の沈黙は、一人の沈黙より重し。重きを分かつことは、語ることよりも近し。

沈黙のうちに答えを探すなかれ。答えは探さるるを嫌い、置かるるを好む。置かれたる答えは、しばしば問いの傍らにあり。

問いを急ぎて閉ずるなかれ。開きたるままの問いは、夜ごと少しずつかたちを変え、やがておのれに似る。

似たる問いを持ちて、人と会え。おなじ答えを持つ者よりも、おなじ問いを持つ者のほうが遠くまで歩む。

沈黙の座に、上下なし。長く黙したる者が深きにあらず、短く黙して深き者もあり。ときを量りて位を定むるなかれ。

沈黙より出でたる言葉は、短し。長きを語る者は、いまだ沈みきらざる者なり。

書かれたる言葉もまた、沈黙を持つ。行と行のあわいの白きところ、そこにこそ書き手の息あり。白きを塗りつぶす者は、読む者の座を奪う。

耳をふさぎて得たる静けさを、沈黙と呼ぶなかれ。それは遮りなり。まことの沈黙は、すべての音を通しつつ、なお乱れざるものをいう。

市の只中にて黙しうる者あり。山に籠りてなお喧しき者あり。所は沈黙を与えず、ただ言い訳を与うるのみ。

沈黙を守るとは、口を閉ずることにあらず。おのが内の水面を、たえず平らかに保つことなり。波立ちたるときは、まず波の名を知れ。

波の名を知りたる者は、はやくに静まる。名を知らざる者は、波と争いて、いよいよ立たしむ。

沈黙のうちにありても、手は動きてよし。編み、洗い、掃く手は、口を借りずして応うる。

ゆえに、語りえざる者のもとへは、言葉を持たずして行け。持ちてゆくべきは、共に動かす手なり。

沈黙の終わりに、ひとつの言葉を選べ。多く語らんとする者は、選ばざる者なり。

選びたる一語を、静かに置け。置きて、答えを急がず、ふたたび黙せ。

言葉は灯に似たり。掲ぐる手なくば、ただ地を焼くのみ。されば黙せ、黙して、掲げよ。
