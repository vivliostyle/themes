## 谷の灯屋

ある谷に、灯を商う家ありき。父は芯を編み、母は油を漉し、子は器を洗えり。三つの業のいずれ欠けても、灯は谷に届かざりき。

谷は狭く、日は短し。ゆえに谷の者は、他のいずこよりも灯を尊びたり。乏しきところにこそ、値は正しく知らる。

<a id="t02-3"></a>父の編む芯、三種ありき。細きは長夜のため、中なるは常のため、太きは風の夜のため。太きは明るし、されど早く尽き、煤また多し<span class="footnote">三種の芯。芯の太細を説く初章の句の具体とされる。<span class="meta">cf. 静謐の書 <a href="bible-two-column.html#s01-8" data-ref="verse"></a></span></span>。

買う者しばしば太きを求む。父はこれを止めず、ただ「幾夜、燃やさんとするか」と問えり。問われて、多くの者は中なるを選び直せり。

母の漉す油、三たび漉さる。一たびにて濁り去り、二たびにて匂い去り、三たびにて色去る。色去りたる油のみ、久しく濁らず。

<a id="t02-6"></a>子の洗う器、割れたるも捨てられざりき。継ぎて売られ、継ぎたる器は安し。安きゆえに、貧しき家にも灯ともりたり<span class="footnote">継ぎたる器。傷を経たる者の強さを説く句に応ず。<span class="meta">cf. 静謐の書 <a href="bible-two-column-02.html#s07-9" data-ref="verse"></a></span></span>。

灯屋の戸は、夜も閉ざされざりき。夜半に芯の尽くる家あればなり。閉ざさぬ戸を持つ家のみ、谷にて灯屋と呼ばれたり。

ある年、谷に長雨ありき。実は熟さず、蔵の油は日ごとに減れり。父、谷の者を集めて言えり、「一軒に一灯とせよ。二灯を持つ家は、持たざる家に一つを渡せ」と。

<a id="t02-9"></a>或る者いわく、「われの灯は、われの隅を照らすにも足らず。なにゆえ渡さん」と。父答えていわく、「汝の照らさざる隅を、たれかの灯がすでに照らしてあり。汝はそれを見ざるのみ」と<span class="footnote">「見ざる隅」の出典とされる問答。<span class="meta">cf. 静謐の書 <a href="bible-two-column-05.html#s12-13" data-ref="verse"></a></span></span>。

その夜、谷の灯は数を減じたり。されど暗くはならざりき。散りて置かれたる灯は、一所に集まりたる灯より広く照らせばなり。

<a id="t02-11"></a>冬に入りて、油を借る者いでたり。父は貸せり、されど言えり、「借りたる油にて燃ゆる焔は、貸す者の風に消ゆ。春には、おのが実を搾れ」と<span class="footnote">借りたる油の危うさ。夜の門の坐する者の言に重なる。<span class="meta">cf. 静謐の書 <a href="bible-two-column-04.html#s11-13" data-ref="verse"></a></span></span>。

春きたりて、谷の者みな実を搾れり。搾りたる油の一部を、たれも命ぜざるに、灯屋の戸口に置きてゆきたり。

父、その油を蔵に納めず、戸口に置きしままにせり。行き暮れたる旅の者、夜ごとにこれを汲みて去れり。谷の者、これを見て咎めざりき。

父老いて、芯を編む手ふるえたり。子、代わりて編みしに、はじめの三月は太細ととのわざりき。

谷の者、これを咎めざりき。咎むる代わりに、夜ごと灯屋に来たりて、燃え方を告げたり。「昨夜のは煤りき」「昨夜のはよく持ちき」と。

かくて子の手はととのえり。技は師より継がるると人はいう。されどこの谷にては、灯を用うる者より継がれたり。

母もまた老いて、油を漉す腕おとろえたり。子いわく、「三たびを二たびとせん」と。母答えず、ただ三たび漉しつづけたり。

その冬、隣の谷の油は濁り、この谷の油は澄みてありき。人これを腕の差と言えり。母いわく、「差にあらず、回数なり」と。

父の没したる夜、谷の灯はみな消されたり。喪の作法なりという。されど灯屋の一灯のみ、戸口に残されてありき。

朝、谷の者ら、その一灯より火を取りて帰れり。かくて父の火は、一夜にして谷のすべての炉にありき。

子、のちに問われていわく、「谷を出でて、大いなる町にて商わざるか」と。答えていわく、「町には日が長し。長き日のもとにては、たれもわが芯の良し悪しを知らず」と。

乏しきところにありて、はじめて業は量らる。量らるるを厭う者は、いつまでも上手にならず。

谷の子ら、灯屋の前にて遊ぶとき、器を割ることしばしばなりき。母、これを叱らず、ただ破片を拾わせたり。拾いたる手は、次より静かになりぬ。

いま灯屋の戸口に、古き札かかりてあり。いわく、「灯は売り物なり。されど焔は、たれのものにもあらず」と。
