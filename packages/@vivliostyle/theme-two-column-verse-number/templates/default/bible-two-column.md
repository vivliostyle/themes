## 初めの灯

夜は古く、灯はそれより若し。ものみな夜のうちに生まれ、夜のうちに名を得たり。灯は名を与うる者にあらず、名の見ゆる場をつくる者なり。

一つの焔、丘の背に起これり。大いならず、音もなく、ただ一点の温みとして立てり。たれが点したるかを知る者なし。ただ点りてありき。

焔は夜を退けず、夜もまた焔を消さず。ふたつならびて在り、そのあわいに、はじめて際というもの生じたり。際あるがゆえに、人は歩みを知れり。

はじめの人、焔を見て問えり、「これは何のためぞ」と。焔は答えず、ただ揺れたり。答えなきを聞くこと、これ最初の学びなりき<span class="footnote">「答えなきを聞く」。無答をもって欠如とせず、教えの一形式とみなす。<span class="meta">cf. 静謐の書 <a href="bible-two-column-02.html#s07-12" data-ref="verse"></a></span></span>。

人、手をのべて焔を抱かんとす。焔はその手を灼けり。ゆえに知る、光は抱くものにあらず、負うものなりと。

人、器を作れり。土をこね、火に入れ、冷まして油を盛れり。器なくして焔は地に落ち、地に落ちたる焔は、おのが座を焼くのみ。

器は焔にあらず、されど器なくして焔は続かず。かたちを侮る者は、やがて続きを失うなり。

<a id="s01-8"></a>芯を編むは人の業なり。芯は油と焔とをつなぐもの。細きにすぎれば消え、太きにすぎれば煤す。そのほどは、編む手のみが知る<span class="footnote">芯の太細については、谷の灯屋の伝に詳しき記述あり。<span class="meta">cf. 灯明譚 <a href="bible-two-column-09.html#t02-3" data-ref="verse"></a></span></span>。

はじめの夜、灯は一つなりき。次の夜、二つとなれり。分かちたるは惜しまざる者なり。惜しみたる者の手には、なお一つのみ残れり。

灯を得たる者ら、丘をくだりて散れり。散りて後、丘はふたたび暗し。されど暗きは失いにあらず、送り出したるしるしなり。

遠く行きたる者は、おのが灯を高く掲げたり。高きは遠くに見ゆ、されど風もまた高きにあり。掲ぐる高さは、風のはかりによるべし。

近く留まりたる者は、灯を低く置けり。低きは足もとを照らす。遠きを照らさざるを恥ずるなかれ、躓かざるはすでに一つの光なり。

夜半にいたりて雨ふれり。雨は焔をきらう。ゆえに人、屋根を編めり。守るとは逃ぐることにあらず、覆いを作ることなり。

<a id="s01-14"></a>覆いを厚くしすぎたる者ありき。焔は息を失いて消えたり。守りもまた過ぐれば殺すなり。ゆえに覆いには、かならず風の道を残せ<span class="footnote">「風の道」。過剰なる庇護を戒むる句として引かる。<span class="meta">cf. 沈黙の巻 <a href="bible-two-column-07.html#c03-9" data-ref="verse"></a></span></span>。

朝きたりて、灯は要らずと言う者ありき。されど朝は去り、夜はまた来たる。要らざる時に灯を捨つる者は、要る時に手ぶらなり。

ゆえに昼のうちに油を蓄えよ。蓄うるは疑いにあらず、夜を知るがゆえの信なり。

油は搾らるるところより出づ。搾らるるを経ざる実は、いかに大いなるも灯を知らず。ゆえに痛みを、無用の道と呼ぶなかれ。

焔を継ぐ者、まず煤を知るべし。煤は焔の子にして、焔の敵なり。おのが業の生む影を見ざる者は、やがてその影に埋もる。

<a id="s01-19"></a>灯守と呼ばるる者ら起これり。呼び名は与えらるるものにて、名乗るものにあらず。みずから灯守と名乗る者、しばしば灯を持たず<span class="footnote">「灯守」の呼称。継ぎたる後に人より与えらるとする規定による。<span class="meta">cf. 静謐の書 <a href="bible-two-column-03.html#s09-5" data-ref="verse"></a></span></span>。

灯守の第一のつとめは、点すことにあらず、絶やさぬことなり。点すは一夜の業、絶やさぬは生涯の業なり。

第二のつとめは、数えぬことなり。数うる手は、拭う手を忘る。

第三のつとめは、問いを退けぬことなり。問う者は敵にあらず、いまだ点らざる芯なり。

灯守ら、丘に小屋を建てたり。壁は低く、戸は閉ざされず。閉ざされたる戸のうちに、灯の意味はなし。

<a id="s01-24"></a>されど小屋は世のただなかに建てられず、また世を離れて建てられず。世の縁にこそ建てらるべし。縁とは、去るにも帰るにもひとしく近き場をいうなり<span class="footnote">「世の縁」の座。隠棲と交わりのいずれにも傾かぬ位置を説く。<span class="meta">cf. 静謐の書 <a href="bible-two-column-05.html#s12-6" data-ref="verse"></a></span></span>。

縁に立つ者は二たびの寒さを負う。外の風と、内の静けさと。これに耐うる者のみ、待つことを知る。

これ初めの灯のことなり。のちの章は、みなこの一点よりひろがれり。読む者よ、はじめに帰ることを恐るるなかれ。
