## 継ぐこと

継ぐとは、受くることにあらず。受けて、なお続くることなり。受けて置く者は、いまだ継ぎたるにあらず。置かれたる火は、置かれたる夜のうちに消ゆ。

<a id="s09-2"></a>同じ火を、同じ手つきにて、幾夜もくり返す者あり。人これを退屈という。されど忠実は、いつも退屈のかたちを取りてあらわる<span class="footnote">反復のうちに忠実を見る思想の典拠。<span class="meta">cf. 静謐の書 <a href="bible-two-column-05.html#s12-9" data-ref="verse"></a></span></span>。

新しき火を誇る者、しばしば古き火を消す。消してのち、火は一つも増えざりき。増えたるは、ただ消したる者の声のみ。

継ぐ者は前の者を讃えず、また責めず。ただその手つきを学ぶ。手つきのうちにこそ、言葉にならざる教えあり。教えは語らるるよりも、写さるるものなり。

<a id="s09-5"></a>灯守の名は、継ぎたる後に人より与えらる。継ぐ前に名を得たる者は、名を守りて火を守らず<span class="footnote">「灯守」の呼称規定。名乗るを禁ずる伝による。<span class="meta">cf. 静謐の書 <a href="bible-two-column.html#s01-19" data-ref="verse"></a></span></span>。

継ぎ目に隙あり。隙より風入る。ゆえに継ぐ夜は、いつも最も危うき夜なり。危うきを知りて、なお継げ。危うからざる継ぎは、いまだ継ぎにあらず。

危うきを避けて継がざる者あり。かくて丘の火は、しばしば争いのうちにあらず、安全のうちに消えたり。

三たび渡されたる火を、古き火という。古きとは齢にあらず、渡されたる回数をいうなり。ゆえに一夜にして古びたる火もあり。

<a id="s09-9"></a>渡す者は、渡すその日を選ばず。選ばれたる日は、たいてい備えなき日なり<span class="footnote">「備えなき日」。継承の突然性を説く。<span class="meta">cf. 沈黙の巻 <a href="bible-two-column-07.html#c03-11" data-ref="verse"></a></span></span>。

ゆえに常に備えよ。備えとは油の量にあらず、注ぐ手にためらいなきをいう。量は蔵に問え、ためらいは夜ごとの手に問え。

継ぎて後、前の者を訪ぬるなかれとは言わず。ただ、問いを持ちて訪ねよ。讃えを持ちて訪ぬる者は、何も持ち帰らず。

継がれざる火もあり。これを咎むるなかれ。すべての火が夜を越ゆるにあらず。越えざりし火もまた、その一夜を確かに照らせり。

<a id="s09-13"></a>消えたる火の跡に立ちて、灰を掬え。灰は油にあらず、されど土を肥やす<span class="footnote">「灰は土を肥やす」。失われたる業の余得を説く。<span class="meta">cf. 静謐の書 <a href="bible-two-column-06.html#s13-4" data-ref="verse"></a></span></span>。

渡す者、渡す前に一つの誤りを告げよ。おのが正しきのみを告ぐる者は、次の者に同じ穴を掘らしむ。

受くる者、受けてのちすぐには改めそ。三月は前の手つきのままに保て。しかる後に、改むべきはおのずと立ちあがる。

されど三年を経てなお改めざるは、継ぎにあらず、写しなり。写しは似て、生きず。

火は継がるるうちに、少しずつ色を変う。変わらざるを誇る者は、いずれ変わりたるを隠す者となる。

二人にて継ぐ夜あり。手と手のあわいに、火はしばし宙にあり。その一瞬を、たれも十分には語りえず。

語りえざるものを、伝という。書に残らざるがゆえに、伝は手より手へとのみ渡る。

継ぎたる後、はじめの夜は長し。おのが手つきの拙きが、火に映りて見ゆればなり。見ゆるは幸いなり、見えざる者は直しえず。

継ぎたるものを、また継がるる日のために整えよ。受けたるままの乱れを次に渡す者は、一つの怠りにて二たびの罪を犯すなり。整えは、いまだ見ぬ者への言葉なり。

前の者の残したる道具のうちに、用を解しがたきもの一つ二つあらん。捨つるなかれ。三年ののち、その用はおのずと分かる。分かるまでは、ただ拭きて置け。

分からざるものを残すこと、これ伝の器量なり。おのが分かるものだけを残す者は、おのが丈だけの火を残す。丈を越えて渡すことは、渡す者にも見えぬ賜なり。

継ぐ者ら、ときに相争う。争いの多くは火をめぐらず、手つきをめぐる。手つきは人に属し、火はたれにも属さざればなり。属せざるものを争うは、いつも空し。

争いのやまざる夜は、二つに分かちて、それぞれの炉に点せ。分かたれたる火もまた、もとの一つの火なり。合わさるる日は、いずれ来たらん。

火を継がざる者もまた、火を守る。用うることは、守ることの一つのかたちなり。谷の灯を保つは、灯守のみの業にあらず。

されば継げ、静かに。継ぐとは、おのが名を消して火を残すことなり。名を残して火を消すは、継ぎの反なり。
