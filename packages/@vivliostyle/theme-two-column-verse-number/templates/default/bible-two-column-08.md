## 影の丈

夜半に目覚む。灯は細く、風はなし。世は眠り、われひとり、燃ゆるものを見てあり。

見つめて久し。焔は同じかたちを二たび取らず。されど同じ焔と、たれもがいう。名は、変わりつづくるものにこそ与えらる。

<a id="y04-3"></a>やがてわれもまた土に還らん。器は砕け、油は尽き、名は風に散らん<span class="footnote">「土に還らん」。器の有限を説く句。<span class="meta">cf. 静謐の書 <a href="bible-two-column-02.html#s07-15" data-ref="verse"></a></span></span>。

されど今宵、焔はここに在り。在ることのほかに、証しを求むるなかれ。

壁に影あり。われの影なり。われより大きく、われより暗し。

影を消さんとして灯を動かす。影もまた動く。逃るる先は、いずこにもなし。

灯を消せば影も消ゆ。さらば影なきは、光なきなり。われ、影とともに在るを選ぶ。

問う声、内より起こる。「汝の火は、たが火ぞ」と。夜半の問いは、いつも短し。

<a id="y04-9"></a>われ答う、「知らず」と。知らずと言いて、はじめて息やすし<span class="footnote">「知らず」の答。夜の門の問答に受け継がる。<span class="meta">cf. 静謐の書 <a href="bible-two-column-04.html#s11-5" data-ref="verse"></a></span></span>。

知らざることを、闇と呼ぶなかれ。知らざるは、いまだ照らされざるのみ。

夜半は長し。されど長きは、深きの別の名なり。浅き夜に、たれも問いを持たず。

遠くに一つ、灯の見ゆ。たれのものとも知らず。知らずして、なお心強し。

かの灯もまた、われを見てあらん。見られてあることを、われは忘れがちなり。

<a id="y04-14"></a>しばし何もせず坐す。芯も切らず、油も足さず、ただ坐す。この時のうちに、われは最も多く受く<span class="footnote">坐して何もせざる時。灰をあらたむる章にも同じ勧めあり。<span class="meta">cf. 静謐の書 <a href="bible-two-column-06.html#s13-12" data-ref="verse"></a></span></span>。

手を膝に置けば、手の疲れを知る。知りて、はじめていたわる。知らざるうちは、いたわりも届かず。

立ちて壁に近づく。影は縮み、濃くなる。

<a id="y04-17"></a>退けば影は伸び、薄くなる。影はその丈を示す。丈は、光との隔たりによる<span class="footnote">「影はその丈を示す」。自己審査の隠喩の出典。<span class="meta">cf. 静謐の書 <a href="bible-two-column-05.html#s12-11" data-ref="verse"></a></span></span>。

ゆえに影の大いなるを嘆く者よ、汝はただ光より遠きのみ。歩を寄せよ、それにて足る。

近づきて灼かるるを恐るるか。恐れよ。恐れは礼のはじめなり。

されど恐れて留まるなかれ。留まる者の影は、幾年ののちも同じ丈のままなり。

壁を替えたる夜あり。影は別のかたちを取れり。われは変わらず、ただ受くる面の変わりたるのみ。

ゆえに人の言うわが影を、われとするなかれ。かの者の壁の凹凸を、われは知らざればなり。

灯を床に置けば、影は天井に届く。高きに掲ぐれば、影は足もとに縮む。

掲げよ、と古き者は言えり。おのが影を小さくせんがためにあらず、道を広く照らさんがためなり。

夜半をすぎて、油の減るを見る。減りたる分だけ、夜は照らされてありき。惜しむべきものは、なにもなし。

遠くの灯、いつしか消えたり。眠りたるならん。消えたるを悲しまず、明日の夜をわれは待つ。

芯の先に、小さき玉のごときもの育ちてあり。切るべしと知る。されど今しばらくは、その形を見てあらん。

やがて鋏を取る。切りたる先は、灰となりて落つ。落ちたるものは、昨夜のわれに似てあり。

焔、ひととき高く立ちて、また常のたけに戻る。整うるとは、常に戻すことなり。高きに留めんとする者は、油を早く失う。

遠くの丘に、いま一つの灯ともりたり。だれか、われと同じ夜に目覚めてあらん。

問わず、呼ばず、ただ見てあり。見ゆることのみにて、夜はすでに二人のものなり。

東の空、いまだ白まず。それにてよし。夜はなお、われに与えられたる時なり。

灯よ、朝までは要らぬ。ただ、われの目覚めてあるうちは、静かに燃えてあれ。
