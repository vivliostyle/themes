## 灰をあらたむ

朝は灯を消す時にあらず、灰をあらたむる時なり。消ゆるはおのずから起こり、あらたむるは手による。手の要らざるものを、業とは呼ばず。

灰を掻き出さぬ炉は、やがて息を失う。積もりたるは過去にあらず、いまを塞ぐものなり。塞がれたる炉に、いかなる薪も燃えず。

されど灰をことごとく捨つるなかれ。ひとつまみの灰は、火の座を温かく保つ。すべてを捨つる者は、毎朝あらたに凍える。

<a id="s13-4"></a>残したる灰を畑にまきたる者ありき。翌年、その畝の麦のみ、丈高く実れり。燃え尽きたるものは、なお養う<span class="footnote">「燃え尽きたるものは、なお養う」。灰の効用を説く句。<span class="meta">cf. 静謐の書 <a href="bible-two-column-03.html#s09-13" data-ref="verse"></a></span></span>。

ゆえに終わりを敗れとするなかれ。終わりたる業は、かたちを変えて土に残る。残りたるを見えざるは、見る目のいまだ育たざるがゆえなり。

朝ごとの手入れを、業のうちの小事とする者あり。さらば問え、大事はいずこにありやと。答え得ざるならば、それは大事を持たざるにあらず、小事を侮りたるなり。

大いなる夜は、小さき手入れの積みかさねに支えらる。支えを見ざる者は、支えを侮る。侮られたる支えは、音もなく退く。

芯を切れ。切りすぎたる芯は焔を細らせ、切らざる芯は煤を生む。切るは日ごとの判断にして、定めごとにあらず。定めに頼る者は、いつか焔を見ずして鋏を持つ。

器を伏せて乾かせ。伏せざる器に露たまり、露は油を濁らす。見えざる水こそ、最も光を曇らすものなり<span class="footnote">「見えざる水」。内なる濁りを心の惰性にたとえる。<span class="meta">cf. 静謐の書 <a href="bible-two-column-05.html#s12-15" data-ref="verse"></a></span></span>。

油壺を日に曝すなかれ。よき油は暗きに熟す。あらわに置かるるものは、はやく古ぶ。人もまたしかり、と言う者あり。

道具を並べよ、おのが手の順に。他人の順に並べたる道具は、夜半に見つからず。夜半に見つからざる道具は、持たざるにひとし。

<a id="s13-12"></a>手入れの終わりに、しばし炉のまえに坐せ。坐して何もせざる時を、怠りと呼ぶなかれ<span class="footnote">坐して何もせざる時。夜半の詩にも同じ勧めあり。<span class="meta">cf. 夜半の詩 <a href="bible-two-column-08.html#y04-14" data-ref="verse"></a></span></span>。

その時のうちに、汝は昨夜のおのれを見る。見て、責めず、ただ書き留めよ。責むる者は書き留めず、書き留めざる者は同じ夜をくり返す。

<a id="s13-14"></a>書き留めたるものを、七日ののちに読め。そのとき、責むべきの多くはすでに直りてあり<span class="footnote">日を置きて省みる作法。熱きうちの省みを裁きとする。<span class="meta">cf. 沈黙の巻 <a href="bible-two-column-07.html#c03-12" data-ref="verse"></a></span></span>。

なお残れるものこそ、汝の癖なり。癖は直らず、ただ知らるるのみ。知られたる癖は、もはや汝を欺かず。

炉のまわりを掃きたる後、戸を開けよ。夜のあいだの匂いは、朝の風にのみ去る。とどめおかるる匂いは、やがて味となる。

あらたむる者、しばしば一人なり。人は燃ゆる焔を見に来たれども、灰を掻く手を見に来たらず。

それでよし。見らるるための手入れは、三日にして途絶ゆ。見られざるがゆえに、この業は続く。

かくて日はくり返す。くり返しを退屈とする者は、灯を長くは守れず。

朝ごとの炉は、いつも少しずつ異なる。同じと見ゆるは、見る者の目の粗きによる。粗きを恥ずるなかれ、日を重ぬれば目は細かくなる。

手入れの順を、みだりに変うるなかれ。順は覚えのためにあらず、忘れてもなお過たざるためなり。

されど年に一たびは、順のことごとくを疑え。疑いて、なお変えざるならば、その順は汝のものとなれり。

炉の灰のなかに、去年の釘のいでたる朝ありき。用なきものと捨てんとして、しばし手に持ちてありき。

捨てたるは、その日の夕なりき。持ちてありし半日を、たれも業とは呼ばず。されどその半日のうちに、われは一つの夜を思い出せり。

手を動かす業のうちには、かならず思い出す時が含まる。含まれざる手入れは、はやし、そして浅し。

灰を捨つる場を、遠くに定めよ。近きに積む者は、風の日にそれを吸う。捨てたるものは、捨てたる場にとどまらず。

朝の手入れを終えて、はじめて夜を語れ。語る前に手を動かす者のみ、夜の長さを正しく言いうるなり。

これ、灰をあらたむる者の章なり。読みて後、まず汝の炉を見よ。見て、手を動かせ。
