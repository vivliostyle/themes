## 夜の門

夜に門あり。見えざれども、たれもみなそこを通る。通りしことに気づく者は少なし。気づかざるがゆえに、門は今も閉ざされず。

門に鍵なし。ただ、灯なき者はその前にて立ちどまる。閉ざされたるにあらず、見えざるのみ。見えざる戸は、鍵より固し。

門番ありき。名を問わず、行き先を問わず、ただ「汝の火はたれより来たれるか」とのみ問えり。

答うる者、しばしば言葉に詰まる。おのが火の出どころを、たれも十全には知らざればなり。

<a id="s11-5"></a>門番いわく、「知らずと言え。知らずと言う者を、われは通す。知れりと言う者のみ、われはしばし押しとどむ」と<span class="footnote">「知らずと言え」。出自の不可知を前提とする問答形式。<span class="meta">cf. 夜半の詩 <a href="bible-two-column-08.html#y04-9" data-ref="verse"></a></span></span>。

門をくぐりて後、夜はいよいよ深し。深きは罰にあらず、門の内側の色なり。色を恐るる者は、門にて引き返す。

急ぎて渡りたる者あり。朝の来たる前に着けり、されどその灯は消えてありき。

遅れて渡りたる者あり。日高くなりて着けり、されどその灯はなお燃えてありき。

いずれを善しとするかを、この書は定めず。ただ、着きたる時に手のうちにあるものを見よと言う。

夜半、道のかたわらに坐する者あり。行くにもあらず、帰るにもあらず。これを迷いという者あり、これを待ちという者あり。

坐する者に問えり、「なにゆえ進まざる」と。答えていわく、「わが灯、いまだわが灯にあらず。借りたる火にて夜を渡らじ」と<span class="footnote">「借りたる火」。信の自立を説く句として引かる。<span class="meta">cf. 沈黙の巻 <a href="bible-two-column-07.html#c03-5" data-ref="verse"></a></span></span>。

借りたる火もまた火なり。されど借りたる火にて渡る夜は、渡るごとに借りを増す。増えたる借りは、朝に請わる。

<a id="s11-13"></a>おのが芯に、おのが油を吸わせよ。他人の油に燃ゆる焔は、他人の風に消ゆ<span class="footnote">他人の油に依る危うさ。谷の灯屋の言い伝えと重なる。<span class="meta">cf. 灯明譚 <a href="bible-two-column-09.html#t02-11" data-ref="verse"></a></span></span>。

されど初めの一点は、かならず他より来たる。これを恥とするなかれ。恥ずべきは、他より来たれるものを、永く他のままに置くことなり。

道のなかばに、灯を捨つる者あり。重きがゆえにあらず、照らさるるを厭うがゆえなり。おのが足を見るを恐るる者は、暗きを友とす。

その者ら、闇のうちにては速し。されど朝いたりて、いずこより来たれるかを言いえず。速さは、しばしば道を消す。

灯を捨てざるも、これを袖に隠す者あり。人に見えざれば、問わるることなしと思うがゆえなり。されど隠されたる灯は、まず持ち主の胸を焦がす。

夜の道に、標なし。あるは先を行きたる者の落としたる灰のみ。灰を数えて進む者は遅く、されど迷わず。数えざる者は速く、しばしば同じ木の下に戻る。

灰を見ずして、星のみを仰ぎて進む者あり。星は美し、されど足もとを教えず。二つながら見る者は首を痛む。それでも、二つながら見よ。

道のかたわらに、水の湧く場あり。灯を持つ者は、しばしばこれを見過ごす。光あるがゆえに、渇きを忘るることあり。灯は渇きを癒さず。

渇きて水を求むる者に、灯を差し出すなかれ。差し出さるべきは、水なり。人はしばしば、おのが持てるものを与えて、与えたりと思う。

門をふたたび見んとして、引き返す者あり。夜の門は、来たる道にのみ立ち、帰る道には立たず。過ぎたるものを訪ぬるなかれ。

されど門は帰る者にも開く。開くは、同じ門にあらず、次の夜の門なり。夜ごとに門は建てらる。

帰る者に問う言葉は、ただ一つ、「汝の火はなお在るか」と。行き先も、遅速も、問わるることなし。

在ると答え得る者は、幾たびも通りてよし。無しと答うる者には、門番みずからの灯より一点を分かつ<span class="footnote">門番の分与。焔は分かちても減らずとする理解による。<span class="meta">cf. 静謐の書 <a href="bible-two-column-05.html#s12-16" data-ref="verse"></a></span></span>。

門番、幾たび分かちても、なお暗からず。これ、門の古きならわしなり。ならわしを疑う者は、みずから一たび分かちて見よ。
