# 灯台への坂 {#todai}

<aside class="sidebar">

坂の上まで徒歩四十分。水を一本持って上がりたい。

</aside>

町でただ一本、水路から離れていく道がある。東のはずれから坂になって、山へ上がっていく道だ。

石段ではなく、踏み固められた土の道である。両側は{夏蜜柑|なつみかん}の畑で、実の落ちる音が、ときどき葉のなかで鳴った。

道は途中で二度折れる。折れるたびに、海の見える角度が変わる。はじめは水路の出口が、次は港の全体が、最後には沖の島までが視野に入ってくる。

畑のあいだに、石を積んだだけの{祠|ほこら}があった。屋根はなく、なかに小さな舟の模型が一つ置かれている。供えられたものらしい。

坂の入口には、荷を下ろすための古い{索道|さくどう}の柱が残っている。夏蜜柑を運ぶのに使ったもので、いまは架線がない。

柱は三本。あいだの二本は倒れ、いちばん上の一本だけが立っている。

十分も上がると、屋根がそろって下に見えた。水路はそこからだと銀色の細い線で、町を五つに分けているのがはっきりわかる。

<aside class="sidebar">

灯台は内部非公開。まわりの草地までは自由に入れる。

</aside>

上がるにつれて水路の匂いが薄くなり、かわりに草と土の匂いが強くなる。町にいるあいだは気づかなかったが、あの匂いはずっと足もとにあったのだ。

坂をのぼりきったところに、{鷺首|さぎくび}灯台が立っている。白い、細い塔で、思っていたよりずっと小さい。

扉は閉ざされ、鍵に錆が浮いていた。壁の白は塗り直されたばかりらしく、継ぎ目のところだけ色が違う。だれも住まなくなった建物のほうが、かえって手入れが行き届いて見えることがある。

塔の足もとには、古い{油壺|あぶらつぼ}が二つ置かれていた。灯が油だったころのもので、いまは草に埋もれかけている。

灯台守はもういない。年に何度か船で人が来て、灯を確かめて帰るのだという。

草地のはしに立つと、海がひらけていた。{小鷗島|こおうじま}という低い島が沖に一つあり、そのむこうはもう、水と空の見わけがつかない。

島の名は、鷗ではなく、鷗のかたちの岩から来ているらしい。

島には、いまも三軒だけ人が住んでいるという。連絡の舟は週に二度。霧の日は出ない。

<aside class="sidebar">

帰りは同じ道を下る。夕方は霧が出やすい。

</aside>

帰りは、来た道を下った。町は、上から見ていたときよりも早く近づいてくる。

坂の途中で振り返ると、灯台はもう霧の下にはいっていた。あの高さにも、霧は来るのだ。

坂の下で、夏蜜柑を売っている人に会った。畑の持ち主ではなく、落ちたものを拾って売っているのだという。籠に六つで、値は言われた分だけ払った。

水路まで戻ると、潮は引いていた。杭の下のほうに、濡れた色の帯が残っている。町はその帯の高さを、一日に二度おぼえ直している。

町に入ると、灯りがひとつずつ点きはじめていた。どの灯りも店の奥のもので、通りに出ているのはその余りだ。着いた朝に見たものと、順序だけが逆になっている。

宿の窓の下では、また舟が通っていた。三日のあいだに、あの音だけは聞き分けられるようになった。

三日いて、地図はとうとう一度も開かなかった。かわりに、潮の時刻を書いた紙を一枚、帳場からもらって帰った。
