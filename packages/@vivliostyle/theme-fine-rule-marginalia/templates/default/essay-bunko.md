# 霧のあがる朝 {#kiri}

<aside class="sidebar">

峠をこえるバスは一日四便。朝いちばんは六時五十分発。

</aside>

{霧津|きりつ}へは、峠をこえる朝いちばんのバスで入った。窓の外はしばらく杉ばかりで、山あいがひらけたとたん、白いものが谷いっぱいにたまっているのが見えた。雲ではない。町がまるごと、そのなかに沈んでいるのだった。

バスは速度をおとし、霧のなかへ降りていく。標識も家並みもいちど見えなくなり、運転手はときどき短く警笛を鳴らした。対向車のためではない、道に人がいるかもしれないからだと、あとになって教わった。

終点で降りると、外套の肩がもう湿っていた。傘はいらない。霧は降ってくるのではなく、こちらの高さで止まっているだけだからだ。手のひらを開いていても、そこには何も落ちてこない。

停留所の時刻表には、上りと下りが四本ずつ書かれている。町の人はこれを峠の四本と呼び、最後の一本にだけ{終|しま}い便という別の名をつけている。

乗りおくれれば、その日は否も応もなく一泊になる。宿が多いのは、そのせいらしい。

<aside class="sidebar">

宿「汐待」は水路の東岸。停留所から歩いて十分ほど。

</aside>

停留所から水路までは、ゆるい下り坂だった。両側の店にはもう灯りが入っている。看板の灯りではない。土間の奥にさがった裸電球の、あまった光が通りにこぼれているのだ。

宿は水路に面した二階家で、{汐待|しおまち}という。女将の{沖野|おきの}さんは、こちらが名乗るより先に、昼までには晴れますよ、と言った。霧の濃い朝ほど、あとがよく晴れるのだという。

帳場の柱には、潮の時刻を書いた紙が貼ってあった。日ごとに二度ずつ、満ちる時刻と引く時刻が並んでいる。この町では、時計より先にこちらを見るらしい。

通されたのは、水路のうえに張りだした部屋だった。窓を開けると、真下を舟が通る。舟は音を立てない。{櫓|ろ}をこぐ音だけが、しばらく壁づたいに残っていく。

荷をほどくあいだも、下では水が動いていた。潮の満ちてくる時刻なのだと、あとで紙を見てわかった。

階下では、朝の分の米を{研|と}ぐ音がしていた。水の音と区別がつかないので、しばらく耳をすませてしまう。

窓の下を、また一艘が過ぎた。荷はないらしく、水にほとんど沈まないまま流れていく。

<aside class="sidebar">

宿の朝食は七時から。頼めば握り飯にしてもらえる。

</aside>

昼近く、女将の言ったとおりに霧はあがった。晴れるというより、屋根のあたりでいちどほどけて、日の光がそのすきまから水路の底まで落ちた<span class="footnote">霧津では霧はあがると言い、晴れるとは言わない。晴れるのは空、あがるのは町のほうだという理屈らしい。</span>。

町は、そのときはじめて全部の輪郭をあらわした。低い家、低い橋、低い塀。高いものは帆柱と、はるか坂の上の灯台だけだ。

水の色は思っていたより濃く、緑がかっていた。底が見えないのではない。底までの距離が読めないのだ。舟が横切ると、その影だけが確かなものに見えた。

下駄を借りて外へ出た。町を歩くのに地図はいらないと、女将は言う。水路をたどれば、どこへでも出るからだそうだ。

貸してくれた下駄は、鼻緒だけが新しかった。取り替えたばかりなのだそうだ。

石の道は乾きはじめていて、下駄の歯がよく鳴った。音は水路の壁にあたり、すこしおくれて返ってくる。
