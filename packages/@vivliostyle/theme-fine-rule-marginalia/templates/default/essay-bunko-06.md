# あとがき #

<aside class="sidebar">

本文中の時刻や便数は、いずれも取材当時のもの。

</aside>

霧津には三度行った。はじめは仕事のついでに一泊し、二度めは霧を見るために、三度めは、何のためだったか自分でもわからない。

この本に書いたのは、二度めと三度めの旅である。一度めのことは、ほとんど覚えていない。町の名を知って帰ってきただけだった。

書きながら、道順を思い出せない場所がいくつもあった。地図を開かなかったせいだが、開いていたら、たぶん別のことを忘れていたと思う。

水路の町は、歩くたびにかたちを変える。潮が満ちれば道が短くなり、引けば匂いが強くなる。同じ道を二度あるいても、同じ道にはならない。

案内をしてくださった宿の方々、船頭の{与三次|よさじ}さん、名を書くことを断られた市場のみなさんに、あらためてお礼を申し上げる。

<p class="signature">霧のあがる時刻に　　沢渡千秋</p>
