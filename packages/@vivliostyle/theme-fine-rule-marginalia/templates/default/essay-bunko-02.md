# 橋の名をたどる {#hashi}

<aside class="sidebar">

町史は図書館の郷土室で読める。複写は一枚十円。

</aside>

霧津の町は、五本の水路で切られている。もとは干潟に引かれた{澪|みお}で、荷を積んだ舟が通るための道だったと、町史にある。

水路には、それぞれに名がある。上流から順に一の澪、二の澪と呼ぶ土地の言い方と、町史に載っている正式の名とが、いまも並んで使われている。道を聞くときは、前のほうで言うのがはやい。

幅はいちばん広いところで十間ほど、狭いところでは、両岸から手をのばせば荷を渡せる。実際、味噌や醤油の樽が、そうやって行き来していたという。

埋め立てて道路にする話は、これまでに何度も出たらしい。そのたびに立ち消えになったのは、風景を惜しんだからではないという。

潮の出入りがなくなると、町の井戸が塩をふくむ。古い人はそう言い、若い人は笑うが、だれも試したがらない。

水路は、町のかたちそのものだった。道が水にそって曲がり、家が道にそって並び、店の戸口はみな水を向いている。

<aside class="sidebar">

橋の下は満潮時に通れない。舟で回るなら干潮の前後に。

</aside>

橋には、どれにも名がついている。{鷺渡橋|さぎわたりばし}、{灯待橋|ひまちばし}、{蛤橋|はまぐりばし}。

そこで何があったかではなく、そこで何を待ったかにちなむ名なのだと、宿の女将は言った。鷺渡橋は、朝の鷺が対岸へ渡るのを待つ橋。灯待橋は、沖から帰る舟の灯りを待つ橋。

鷺渡橋の欄干には、いまも一羽ぶんの{擦|す}り跡がある。毎朝おなじ場所に立つ鷺がいたと言われれば、そう見えなくもない。

どの橋にも、名を彫った石が親柱に{嵌|は}めてある。字は浅く、指でなぞってはじめて読めるものもあった。

蛤橋だけは由来がはっきりしない。欄干のふくらみが貝の形に似ているからだとも、たもとに貝を売る店があったからだとも言われる。

橋のたもとには水まで石段が降りている。もとは洗い物のための段だという。

三つのほかにも小さな橋はいくつもあるが、名を持たない。板を渡しただけのものは、そのつど掛けかえるので、名をつけてもしかたがないのだそうだ。

どちらでもよいのだろう。名が残り、橋が残っているのなら、待った人のことは、名のほうが覚えている。

<aside class="sidebar">

舟をたのむなら市場の東の桟。声をかければ乗せてくれる。

</aside>

橋は低い。舟で水路を行くと、潮の高い時分には桁が胸のあたりまで下がってくる。

{与三次|よさじ}さんという船頭は、そのたびに櫓を止め、舟を惰性で滑らせながら、身を伏せたまま、はい、あたま、と言う。橋をくぐるあいだだけ、水の音が急に近くなる。

潮のいちばん低い時分には、桁の下に二尺ほどのすきまができる。舟はそこを、こするようにして抜けていく。橋のうえを人が歩いていても、こちらの音には気づかない。

与三次さんは橋の名をひとつずつ言いながら舟を進めた。客に教えるためというより、どこまで来たかを自分で確かめるためらしかった。

たもとの小屋には、以前{橋番|はしばん}が住んでいた<span class="footnote">橋番は町の役ではなく、両岸の家が持ち回りで務めたという。</span>。潮を見て、通る舟に声をかけるのが仕事だったという。

今はだれもいない。それでも戸だけは、まだ開け閉てのできるように直してある。
