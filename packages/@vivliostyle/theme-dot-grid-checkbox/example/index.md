## How It Is Kept

- Nothing goes in the index until it has a page of its own. A line here means
  the thing exists and can be found.
- Numbers are read off the page, never remembered. If a page moves, the number
  moves with it.
- The index is written in ink, like everything else. Entries are struck out,
  not erased.
