# DAYFIELD

## Key

- [ ] An open square — the task is still waiting
- [x] ~~A crossed square, struck through — the task is done~~
- [ ] An arrow and a day — the task was carried forward → 10 OCT

## Marks

- A round bullet is a note. Notes are never crossed out; they are only true or
  no longer true.
- The day sits at the head of the page, opposite the masthead, in the same hand.
- A short rule closes the head of the page. Nothing is written above it.
- Drawings are labelled _fig._, set against the outer margin, caption beneath.
- Every page carries its number at the foot. The index at the front carries the
  same numbers, and nothing is looked for twice.

## This Log

- One page a day. If the day was short, the page stays short.
- Nothing is torn out. A day that went badly is a day that went badly.
- On the last page of the month, whatever is still open gets moved on purpose or
  struck out on purpose. Nothing is left to drift.
- A5, five-millimetre dots, sewn in four sections. The paper takes ink without
  spreading, which is the whole reason for it.

## Kit

- One pen, one pencil, one folding rule, one eraser that is mostly gone.
- Ink is the dark blue-grey. Anything blacker looks unkind on this paper.
- No stickers, no colours, no boxes drawn with a ruler. There is not the time,
  and the page is better without them.
